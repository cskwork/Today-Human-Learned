# Vim — 키보드에서 손을 떼지 않는 텍스트 편집기

> **TL;DR**
> Vim은 모드 기반 편집기로, 처음에는 낯설지만 익히면 마우스 없이 텍스트를 빠르게 조작할 수 있다.

---

## Vim을 왜 쓰는지 감 잡기

대부분의 편집기는 항상 입력 상태다 — 키를 누르면 글자가 입력된다. Vim은 다르다. 기본 상태에서 키는 명령이다. `d`는 삭제, `y`는 복사, `p`는 붙여넣기다. 이 방식 덕분에 손이 키보드 홈 포지션을 벗어나지 않고 파일 전체를 편집할 수 있다. SSH로 원격 서버에 접속했을 때 GUI가 없어도 Vim은 항상 있다. 서버 설정 파일을 빠르게 수정하거나 코드를 탐색할 때 실질적인 도구다.

초보자는 처음에 이렇게 이해하면 된다.

`핵심 흐름: Normal 모드(이동·명령) → Insert 모드(입력) → Normal 모드 → Command 모드(저장·종료)`

## 외워야 할 핵심 용어 5개

| 용어 | 초보자식 설명 |
|---|---|
| Normal 모드 | Vim이 시작될 때의 기본 상태. 키가 명령으로 동작한다. `h/j/k/l`로 이동 |
| Insert 모드 | `i`를 눌러 진입. 일반 편집기처럼 글자를 입력한다. `Esc`로 Normal 모드로 돌아간다 |
| Visual 모드 | `v`를 눌러 진입. 텍스트 범위를 선택한 뒤 복사·삭제·치환 명령을 적용한다 |
| Command 모드 | Normal 모드에서 `:`를 눌러 진입. `:w`(저장), `:q`(종료), `:wq`(저장 후 종료) |
| vimrc | Vim 설정 파일(`~/.vimrc`). 줄 번호 표시, 탭 크기, 단축키 등을 여기서 정의한다 |

## 예를 들어 설명하면

파일 전체에서 "foo"를 "bar"로 바꾸는 작업은 Command 모드 한 줄이면 된다.

```
:%s/foo/bar/g
```

- `%` — 파일 전체 범위
- `s` — substitute(치환)
- `foo` — 찾을 단어
- `bar` — 바꿀 단어
- `g` — 한 줄에 여러 개 있어도 모두 바꿈

같은 작업을 다른 편집기에서 하려면 찾기·바꾸기 대화상자를 열고 마우스를 써야 한다. Vim에서는 키보드만 쓴다.

## 이 단계에서 중요한 판단 기준

Vim을 쓸지 말지의 기준은 단순하다 — GUI가 없는 서버 환경이라면 Vim(또는 nano)이 사실상 유일한 선택이고, 로컬 개발이라면 VS Code 같은 GUI 편집기가 더 빠른 시작점이다.

## 한 줄 요약 — 이것만 기억하면 된다

**Vim은 Normal-Insert-Command 세 가지 모드를 전환하며 동작하는 편집기이고, 이 모드 개념만 이해하면 기본 사용은 시작할 수 있다.**
