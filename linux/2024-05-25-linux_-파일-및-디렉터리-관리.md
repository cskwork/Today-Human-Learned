# Linux: 파일 및 디렉터리 관리

> **TL;DR**
> `find`로 파일을 찾고, `grep`으로 내용을 검색하고, `chmod`로 권한을 바꾼다. 이 세 가지가 일상적인 파일 관리의 핵심이다.

---

## 이 명령어들을 왜 배우는지 감 잡기

리눅스에서 파일을 관리하는 일은 GUI 없이 명령줄로 이루어진다. 수백 개의 파일 중에서 특정 확장자를 찾거나, 파일 안에 특정 문자열이 들어 있는 줄을 뽑아내거나, 권한을 바꿔야 할 일이 자주 생긴다. 이 작업들은 반복적이고 자동화가 쉽기 때문에, 명령어 패턴을 익혀두면 시간을 크게 절약할 수 있다.

초보자는 처음에 이렇게 이해하면 된다.

`핵심 흐름: 파일 찾기(find) → 내용 검색(grep) → 권한 변경(chmod) → 복사(cp)`

## 외워야 할 핵심 용어 5개

| 용어 | 초보자식 설명 |
|---|---|
| `find` | 파일 이름, 확장자, 날짜 등 조건으로 파일을 검색하는 명령어. |
| `grep` | 파일 내용에서 특정 문자열이 있는 줄을 찾아주는 명령어. |
| `chmod` | 파일이나 디렉터리의 읽기/쓰기/실행 권한을 변경하는 명령어. |
| `xargs` | 앞 명령의 출력을 다음 명령의 인자로 넘겨주는 연결 도구. |
| `-a` 옵션 | `cp -a`처럼 쓰면 권한, 타임스탬프 등 파일 속성을 그대로 유지해 복사한다. |

## 예를 들어 설명하면

```bash
# 현재 디렉터리 이하에서 .zip 파일 전체 검색
find . -name '*.zip'

# 모든 파일에서 "count" 문자열이 포함된 줄을 줄 번호와 함께 출력
find . -name "*" | xargs grep -n "count"

# 파일 세 개를 합쳐서 하나로 만들기
cat 1.txt 2.txt 3.txt > 0.txt

# 두 파일을 합치고 정렬해서 저장
cat file1 file2 | sort > file3

# 권한 변경: 소유자에게 읽기 추가, 전체에서 쓰기+실행 제거
chmod u+r secure
chmod ugo-wx secure

# 디렉터리 전체를 속성 포함 복사
cp -a /usr/local/source/ /usr/local/destination/
```

## 이 단계에서 중요한 판단 기준

`find`와 `grep`을 파이프(`|`)와 `xargs`로 연결하면 대부분의 파일 탐색 작업을 한 줄로 해결할 수 있다. 권한 변경 시 `ugo`는 각각 소유자(u), 그룹(g), 기타(o)를 의미한다.

## 한 줄 요약 — 이것만 기억하면 된다

**파일은 `find`로 찾고, 내용은 `grep`으로 검색하고, 권한은 `chmod ugo±rwx`로 제어한다.**

## 나중에 더 깊게 들어가면

- `find`의 `-exec` 옵션으로 검색 결과에 바로 명령 실행하기
- `chmod` 숫자 표기법 (예: `755`, `644`) 이해하기
- `chown`으로 파일 소유자를 변경하는 방법
