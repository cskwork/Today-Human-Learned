# CRUD 쿼리 모음 — Oracle 기초 SQL 레퍼런스

> **TL;DR**
> Oracle에서 테이블을 만들고 데이터를 넣고 꺼내는 기본 쿼리 패턴을 한 곳에 모았다.

---

## CRUD 쿼리를 왜 쓰는지 감 잡기

데이터베이스를 쓰는 이유는 단 하나다. 데이터를 안전하게 저장하고, 필요할 때 빠르게 꺼내기 위해서다. CRUD는 Create(생성), Read(조회), Update(수정), Delete(삭제)의 앞글자를 딴 말로, 모든 데이터베이스 작업의 뼈대다. Oracle에서는 SQL이라는 언어로 이 작업을 수행한다.

처음에는 이렇게 이해하면 된다.

`핵심 흐름: 테이블 정의 → 데이터 삽입 → 조회/수정/삭제`

## 외워야 할 핵심 용어 5개

| 용어 | 초보자식 설명 |
|---|---|
| TABLE | 엑셀 시트처럼 행과 열로 구성된 데이터 저장 공간 |
| SEQUENCE | 자동으로 1씩 증가하는 번호 발급기. 고유 ID를 만들 때 쓴다 |
| PRIMARY KEY | 각 행을 유일하게 식별하는 열. 중복 불가, NULL 불가 |
| ALTER TABLE | 이미 만든 테이블의 구조(열 추가, 수정, 삭제)를 바꾸는 명령 |
| ROW_NUMBER() | 조회 결과에 순번을 매기는 함수. 페이징 구현에 필수 |

## 예를 들어 설명하면

회원 테이블을 만들고, 자동 증가 번호를 붙이는 전형적인 패턴이다.

```sql
-- 테이블 생성
CREATE TABLE member (
  IDX    NUMBER UNIQUE NOT NULL,
  ID     VARCHAR2(20) PRIMARY KEY,
  NAME   VARCHAR2(30) NOT NULL,
  PWD    VARCHAR2(15) NOT NULL,
  EMAIL  VARCHAR2(30),
  JOINDATE DATE
);

-- 자동 번호 시퀀스 생성
CREATE SEQUENCE SEQ_MEMBER_IDX
  START WITH 1
  INCREMENT BY 1
  NOMAXVALUE
  NOCACHE;

-- 데이터 삽입 시 시퀀스 사용
INSERT INTO member (IDX, ID, NAME, PWD)
VALUES (SEQ_MEMBER_IDX.NEXTVAL, 'user01', '홍길동', 'pass123');
```

페이징 쿼리는 `ROW_NUMBER() OVER (ORDER BY ...)` 로 순번을 먼저 매긴 뒤, 바깥 쿼리에서 범위를 자른다.

```sql
SELECT * FROM (
  SELECT ROW_NUMBER() OVER (ORDER BY IDX DESC) RNUM, IDX, NAME
  FROM member
)
WHERE RNUM BETWEEN 1 AND 20;
```

테이블 구조를 나중에 바꿔야 할 때는 `ALTER TABLE`을 쓴다.

```sql
ALTER TABLE member ADD    EMAIL   VARCHAR2(30);   -- 열 추가
ALTER TABLE member MODIFY (EMAIL VARCHAR2(50));   -- 열 수정
ALTER TABLE member DROP COLUMN EMAIL;             -- 열 삭제
```

## 이 단계에서 중요한 판단 기준

INSERT에 시퀀스를 쓸 때는 `NEXTVAL`을 직접 VALUES 절에 넣으면 되고, 같은 INSERT 안에서 현재 값을 다시 참조할 때만 `CURRVAL`을 쓴다.

## 한 줄 요약 — 이것만 기억하면 된다

**테이블 생성 → 시퀀스로 ID 자동화 → CRUD 쿼리 작성 → 필요하면 ALTER로 구조 수정.**

## 나중에 더 깊게 들어가면

- JOIN: 여러 테이블을 연결해서 한 번에 조회하는 방법
- INDEX: 조회 속도를 높이는 색인 구조와 그 트레이드오프
- PL/SQL: Oracle 전용 프로시저 언어로 반복 작업 자동화하기
