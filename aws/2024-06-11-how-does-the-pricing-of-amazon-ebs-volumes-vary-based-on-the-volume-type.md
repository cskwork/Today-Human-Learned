# EBS 볼륨 타입별 요금 — 어떤 디스크를 골라야 하는가

> **TL;DR**
> EBS는 성능(IOPS, 처리량)이 올라갈수록 비싸지며, 용도에 맞는 볼륨 타입을 고르는 것이 비용 최적화의 핵심이다.

---

## EBS 볼륨 타입을 왜 구분하는가

EBS(Elastic Block Store)는 EC2 인스턴스에 붙이는 가상 하드 디스크다. 노트북에도 SSD와 HDD가 가격과 성능이 다르듯, EBS도 여러 타입이 있고 각각 가격이 다르다. 빠른 디스크가 필요할수록, 그리고 초당 처리할 수 있는 작업(IOPS)이 많을수록 요금이 올라간다.

초보자는 처음에 이렇게 이해하면 된다.

`핵심 흐름: 용도 파악 → 필요한 IOPS/처리량 확인 → 볼륨 타입 선택 → 비용 계산`

---

## 외워야 할 핵심 용어 5개

| 용어 | 초보자식 설명 |
|---|---|
| IOPS | 디스크가 1초에 처리할 수 있는 읽기/쓰기 횟수. 높을수록 빠르고 비싸다. |
| gp3 / gp2 | 범용 SSD. 대부분의 서비스에 적합하며 가격 대비 성능이 균형 잡혀 있다. |
| io2 / io1 | 고성능 SSD. IOPS를 직접 지정(Provisioned)할 수 있어 DB 같은 I/O 집약 작업에 쓴다. |
| st1 | 처리량 최적화 HDD. 순차적으로 대용량 데이터를 읽고 쓸 때 적합하다. |
| sc1 | 콜드 HDD. 접근 빈도가 낮은 데이터 보관용으로 가장 저렴하다. |

---

## 예를 들어 설명하면

웹 애플리케이션 하나를 운영한다고 가정한다.

| 용도 | 추천 볼륨 | 대략적인 단가 |
|---|---|---|
| 웹 서버·앱 서버 부팅 디스크 | gp3 | $0.08/GB-월 |
| 트랜잭션 DB (높은 IOPS 필요) | io2 | $0.125/GB-월 + IOPS별 추가 |
| 대용량 로그·데이터 웨어하우스 | st1 | $0.045/GB-월 |
| 장기 아카이브 데이터 | sc1 | $0.015/GB-월 |

스냅샷(EBS 볼륨 백업)은 S3에 저장되며 $0.05/GB-월이 별도로 청구된다.

---

## 이 단계에서 중요한 판단 기준

랜덤 읽기/쓰기가 많고 지연 시간이 중요한 DB라면 io2를, 일반적인 서비스라면 gp3로 시작해 성능이 부족할 때 업그레이드하는 것이 비용 효율적이다.

---

## 한 줄 요약 — 이것만 기억하면 된다

**대부분의 서비스는 gp3로 충분하고, IOPS 보장이 필요한 DB에만 io2를 쓰며, 저빈도 대용량 데이터는 HDD 계열(st1/sc1)로 비용을 낮춘다.**

---

## 나중에 더 깊게 들어가면

- gp2와 gp3의 IOPS 버스트 메커니즘 차이
- io2 Block Express: 최고 성능을 요구하는 SAP HANA·Oracle 같은 엔터프라이즈 DB용 옵션
- EBS 스냅샷 증분 저장 방식과 교차 리전 복사 비용
