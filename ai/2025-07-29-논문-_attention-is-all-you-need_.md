# 논문 "Attention Is All You Need" — 트랜스포머의 탄생

> **TL;DR**
> 2017년 구글이 발표한 이 논문은 RNN 없이 어텐션 메커니즘만으로 번역 모델을 만들었고, 그 구조가 오늘날 GPT와 Claude 같은 모든 대형 언어 모델의 기반이 됐다.

---

## 트랜스포머를 왜 쓰는지 감 잡기

영어 문장을 독일어로 번역하는 문제를 생각해보자. 입력과 출력의 단어 수가 다르고 어순도 다르다. 이처럼 길이가 다른 두 시퀀스를 변환하는 문제를 시퀀스 변환(sequence transduction)이라고 한다.

2017년 이전에는 RNN(순환 신경망), 특히 LSTM이 이 문제의 표준 해법이었다. RNN은 단어를 한 개씩 순서대로 처리한다. 그래서 문장이 길어질수록 병렬 처리가 어렵고, 멀리 떨어진 단어 간 관계를 학습하기도 힘들다.

이 논문의 핵심 주장은 단순하다. "어텐션만으로 충분하다." RNN을 완전히 제거하고 어텐션 메커니즘만으로 인코더-디코더 구조를 만든 것이 트랜스포머다.

초보자는 처음에 이렇게 이해하면 된다.

`핵심 흐름: 입력 문장 → 인코더(어텐션으로 의미 파악) → 디코더(어텐션으로 번역 생성) → 출력 문장`

## 외워야 할 핵심 용어 5개

| 용어 | 초보자식 설명 |
|---|---|
| 어텐션(Attention) | 번역할 때 입력 문장에서 어떤 단어에 집중해야 하는지 가중치를 계산하는 장치 — 형광펜으로 중요한 부분에 밑줄 긋는 것과 같다 |
| 셀프 어텐션(Self-Attention) | 한 문장 안에서 단어들이 서로를 참조해 각 단어의 의미를 맥락에 맞게 파악하는 방식 |
| 멀티-헤드 어텐션(Multi-Head Attention) | 같은 문장을 여러 관점(문법, 의미, 위치 등)에서 동시에 분석하는 방식 — 여러 색의 형광펜을 동시에 쓰는 것 |
| 위치 부호(Positional Encoding) | 트랜스포머는 RNN처럼 순서를 자동으로 알지 못하므로, 각 단어의 위치 정보를 사인·코사인 파형으로 주입한다 |
| 잔차 연결(Residual Connection) | 각 레이어를 거친 후 이전 정보를 그대로 더해주는 구조 — 학습이 안정되고 정보 손실을 막는다 |

## 예를 들어 설명하면

영어→독일어 번역 벤치마크(newstest2014) 결과를 보면 트랜스포머의 효과가 명확하다.

| 모델 | BLEU 점수 | 특징 |
|---|---|---|
| GNMT + RL (구글 RNN 기반) | 26.30 | 당시 최고 RNN 모델 |
| ConvS2S (CNN 기반) | 25.16 | CNN 기반 seq2seq |
| Transformer (base) | 27.3 | 어텐션만 사용, 12시간 학습 |
| Transformer (big) | 28.4 | 더 큰 모델, 3.5일 학습 |

BLEU 점수(번역 품질 지표)에서 기존 최고 모델을 2점 이상 앞섰고, 학습 속도도 훨씬 빠르다. 병렬 처리가 가능하기 때문이다.

## 이 단계에서 중요한 판단 기준

RNN 대신 트랜스포머를 선택하는 핵심 이유는 병렬화다 — 셀프 어텐션은 모든 위치 간 의존성을 한 번에 계산하므로, 문장이 길어도 학습 속도가 떨어지지 않는다.

## 한 줄 요약 — 이것만 기억하면 된다

**트랜스포머는 RNN 없이 어텐션만으로 더 빠르고 더 정확한 번역을 달성했고, 이 구조가 현재 모든 LLM의 기반이다.**

## 나중에 더 깊게 들어가면

- 스케일드 닷-프로덕트 어텐션의 수식과 왜 스케일링이 필요한지
- 디코더의 마스킹(Masking)이 어떻게 미래 단어를 차단하는지
- BERT, GPT 등 후속 모델들이 트랜스포머를 어떻게 변형해 사용했는지
