# 나이브 베이즈 — 확률로 분류하는 가장 단순한 머신러닝 모델

> **TL;DR**
> 나이브 베이즈는 각 특성이 독립적이라고 가정하고 베이즈 정리를 적용해 분류 결과를 확률로 계산하는 모델이다.

---

## 나이브 베이즈를 왜 쓰는지 감 잡기

스팸 필터는 이메일이 도착하는 순간 "이게 스팸일 확률은 얼마나 되지?"를 계산해야 한다. 복잡한 딥러닝 모델 없이도, 학습 데이터에서 단어별 출현 빈도만 세면 꽤 정확하게 분류할 수 있다. 이 원리가 나이브 베이즈다. 계산이 단순하고 학습 속도가 빠르기 때문에, 텍스트 분류처럼 특성(단어)이 매우 많은 상황에서 여전히 자주 쓰인다.

초보자는 처음에 이렇게 이해하면 된다.

`핵심 흐름: 클래스별 사전 확률 계산 → 특성별 조건부 확률 계산 → 새 데이터에 곱해서 가장 큰 클래스 선택`

## 외워야 할 핵심 용어 5개

| 용어 | 초보자식 설명 |
|---|---|
| 베이즈 정리(Bayes' theorem) | "증거가 주어졌을 때 어떤 일이 일어날 확률"을 구하는 수식. P(C|X) = P(X|C) * P(C) / P(X). |
| 사전 확률(Prior) | 데이터를 보기 전에 이미 알고 있는 클래스 비율. 스팸 메일이 전체의 30%라면 P(스팸) = 0.3. |
| 우도(Likelihood) | 특정 클래스일 때 해당 특성이 등장할 확률. 스팸에서 "할인"이라는 단어가 얼마나 자주 나오는지. |
| 나이브 가정(Naive assumption) | 모든 특성이 서로 독립적이라고 가정하는 것. 현실에서는 틀릴 수 있지만 계산을 크게 단순화한다. |
| 사후 확률(Posterior) | 데이터를 본 후 계산된 최종 확률. 가장 높은 사후 확률을 가진 클래스로 분류한다. |

## 예를 들어 설명하면

이메일에 "buy"와 "discount"라는 단어가 둘 다 있을 때 스팸 여부를 판별한다고 하자.

학습 데이터에서 계산한 값:
- P(스팸) = 0.4, P(정상) = 0.6
- 스팸일 때 "buy" 등장 확률 = 0.8, "discount" 등장 확률 = 0.7
- 정상일 때 "buy" 등장 확률 = 0.1, "discount" 등장 확률 = 0.05

나이브 가정 하에 각 클래스의 점수를 계산한다.

```
스팸 점수  = 0.4 * 0.8 * 0.7 = 0.224
정상 점수  = 0.6 * 0.1 * 0.05 = 0.003
```

스팸 점수가 훨씬 높으므로 이 이메일은 스팸으로 분류된다.

실무에서는 확률값이 작아지는 문제를 피하려고 로그를 취해 합산한다(`log(P(C)) + sum(log(P(Xi|C)))`).

## 이 단계에서 중요한 판단 기준

특성 간 독립성이 심하게 위반되거나 특성 간 상관관계가 중요한 문제라면 나이브 베이즈보다 로지스틱 회귀나 그래디언트 부스팅이 낫다. 텍스트 분류처럼 특성이 수천 개이고 학습 데이터가 부족할 때는 나이브 베이즈가 여전히 실용적이다.

## 한 줄 요약 — 이것만 기억하면 된다

**나이브 베이즈는 특성 독립 가정 덕분에 계산이 단순하고 텍스트 분류에 특히 강한 확률 기반 분류 모델이다.**

## 나중에 더 깊게 들어가면

- 가우시안 나이브 베이즈: 연속형 특성을 정규 분포로 모델링하는 변형
- 라플라스 스무딩: 학습 데이터에 없던 단어가 나왔을 때 확률이 0이 되는 문제 해결
