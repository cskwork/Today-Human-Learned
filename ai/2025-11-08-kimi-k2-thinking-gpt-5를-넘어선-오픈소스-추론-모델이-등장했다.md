# Kimi K2 Thinking — GPT-5를 넘어선 오픈소스 추론 모델이 등장했다

> **TL;DR**
> Moonshot AI가 공개한 Kimi K2 Thinking은 460만 달러의 학습 비용으로 GPT-5를 주요 벤치마크에서 앞선 1조 파라미터 오픈소스 추론 모델이다.

---

## Kimi K2 Thinking를 왜 쓰는지 감 잡기

AI 모델을 고를 때 보통 GPT나 Claude를 떠올린다. 그런데 2025년 11월, 중국의 스타트업 Moonshot AI가 이 구도를 흔들었다. 1조 개의 파라미터(변수)를 가진 모델을 오픈소스로 공개했고, 성능은 GPT-5와 Claude Sonnet 4.5를 주요 벤치마크에서 앞질렀다.

이 모델이 중요한 이유는 성능만이 아니다. 학습 비용이 약 460만 달러로, 대형 빅테크 모델 대비 수백 분의 일 수준이다. 오픈소스이므로 누구나 내려받아 연구하거나 상업적으로 활용할 수 있다(Modified MIT 라이선스).

실무에서 이 모델이 빛나는 영역은 "여러 단계를 거쳐 복잡하게 해결해야 하는 작업"이다. 웹 검색, 코드 실행, 검증을 200~300회 연속으로 반복하며 문제를 푸는 에이전트형 작업에서 기존 모델보다 월등하다.

초보자는 처음에 이렇게 이해하면 된다.

`핵심 흐름: 질문 입력 → 생각 → 검색/코딩 → 검증 → (200회 반복) → 최종 답변`

## 외워야 할 핵심 용어 5개

| 용어 | 초보자식 설명 |
|---|---|
| Thinking Model | AI가 답을 바로 내놓지 않고, 중간 사고 과정을 단계별로 드러내며 추론하는 모델 |
| Agentic AI | 도구(검색, 코드 실행 등)를 자율적으로 연속 호출하며 복잡한 작업을 스스로 처리하는 AI |
| MoE (Mixture-of-Experts) | 1조 파라미터 중 320억만 골라 활성화하는 아키텍처 — 전체를 쓰지 않으므로 실행 비용이 낮다 |
| INT4 양자화 | 모델 가중치를 4비트 정수로 압축하는 기술 — 추론 속도 2배, 메모리 절반 |
| 컨텍스트 윈도우 | 모델이 한 번에 읽고 기억할 수 있는 텍스트 분량 — Kimi K2 Thinking은 약 19만 단어(256K 토큰) |

## 예를 들어 설명하면

웹에서 복잡한 주제를 심층 리서치해야 한다고 가정하자. OpenRouter를 통해 API로 연결하면 다음처럼 사용할 수 있다.

```bash
# OpenRouter CLI 설치
llm install llm-openrouter

# API 키 설정
llm keys set openrouter

# 모델 호출
llm -m openrouter/moonshotai/kimi-k2-thinking \
  '딥러닝 기반 신약 개발의 최신 동향을 단계별로 정리해줘'
```

이 모델은 요청을 받은 후 논문 검색, 내용 분석, 교차 검증을 수백 번 반복한 뒤 결과를 돌려준다. 단순 질답 AI와 달리, 복잡한 멀티스텝 작업을 혼자 처리한다.

요금은 출력 기준 백만 토큰당 $2.50로, GPT-5($10)보다 훨씬 저렴하다.

## 이 단계에서 중요한 판단 기준

Kimi K2 Thinking은 단순한 질문보다 "여러 단계가 얽힌 복잡한 작업"에서 진가를 발휘하므로, 단발성 대화보다 에이전트형 워크플로우에 먼저 투입해야 한다.

## 한 줄 요약 — 이것만 기억하면 된다

**수백 번 도구를 연속 호출하며 복잡한 문제를 스스로 해결하는 오픈소스 추론 에이전트 모델이다.**

## 나중에 더 깊게 들어가면

- MoE 아키텍처에서 "어떤 전문가(Expert)"를 언제 활성화하는지 결정하는 라우팅 메커니즘
- INT4 양자화 인식 학습(QAT)이 일반 양자화와 다른 이유
- 로컬 실행 환경 구성 (Ollama + Apple M3 Ultra 또는 NVIDIA H100)
