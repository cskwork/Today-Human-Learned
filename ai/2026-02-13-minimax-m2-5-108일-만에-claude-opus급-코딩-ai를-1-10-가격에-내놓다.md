# MiniMax M2.5: 108일 만에 Claude Opus급 코딩 AI를 1/10 가격에 내놓다

> **TL;DR**
> MiniMax M2.5는 108일간 3세대 진화를 거쳐 SWE-Bench Verified 80.2%를 달성하면서, 경쟁 모델 대비 1/10 수준의 가격을 실현한 오픈소스 코딩 모델이다.

---

## 이 주제를 왜 쓰는지 감 잡기

프론티어 AI 모델을 쓰려면 비싼 API 비용은 감수해야 한다는 것이 2025년까지의 상식이었다. 복잡한 에이전트 워크플로를 24시간 돌리면 토큰 비용이 빠르게 누적된다.

MiniMax M2.5는 이 전제를 뒤집었다. SWE-Bench Verified 80.2%, 작업 완료 속도 37% 향상, 그러면서 출력 토큰 가격은 경쟁 모델의 1/10에서 1/20 수준이다. 2021년 SenseTime 출신 엔지니어들이 설립한 상하이 스타트업이 2025년 10월 M2를 시작으로 108일 만에 세 번의 메이저 업데이트를 거쳐 여기까지 왔다.

`핵심 흐름: M2 (비용/접근성) → M2.1 (다국어/안정성) → M2.5 (SOTA 코딩, 에이전트, 오피스)`

## 외워야 할 핵심 용어 5개

| 용어 | 초보자식 설명 |
|---|---|
| SWE-Bench Verified | 실제 GitHub 이슈를 AI가 해결하는지 측정하는 공개 코딩 벤치마크 |
| MoE (Mixture of Experts) | 230B 파라미터 중 추론 시 10B만 활성화하는 구조. 비용을 낮추면서 용량은 유지한다 |
| Forge | MiniMax 자체 개발 Agent RL 프레임워크. 훈련 엔진과 에이전트를 분리해 약 40배 훈련 가속 |
| 인터리브드 씽킹 | 답변과 추론 과정이 번갈아 가며 나오는 방식. 히스토리에 thinking 콘텐츠를 유지해야 성능이 나온다 |
| BrowseComp | 웹 검색 및 깊은 페이지 탐색 능력을 측정하는 에이전트 벤치마크 |

## 예를 들어 설명하면

108일간의 진화를 수치로 보면 이렇다.

| 지표 | M2 (2025-10) | M2.1 (2025-12) | M2.5 (2026-02) |
|---|---|---|---|
| SWE-Bench Verified | 69.4% | ~77% | 80.2% |
| BrowseComp | 44.0% | 개선 | 76.3% |
| 작업 완료 속도 | 기준 | 기준 | M2.1 대비 37% 단축 |

가격 구조가 핵심이다.

| 버전 | 출력 가격 (1M 토큰) | 시간당 비용 |
|---|---|---|
| M2.5-Lightning | $2.4 | ~$1 |
| M2.5 (Standard) | $1.2 | ~$0.3 |
| Claude Opus 4.5 (참고) | ~$15 | 높음 |

MiniMax는 "1만 달러면 4개의 M2.5 에이전트를 1년 내내 연속 가동할 수 있다"고 설명한다. 에이전트를 지속적으로 운영해야 하는 팀에게 실질적인 의미가 있는 수치다.

## 이 단계에서 중요한 판단 기준

M2.5 벤치마크 결과 상당수는 MiniMax 내부 테스트(RISE, GDPval-MM)에 기반한다. SWE-Bench Verified 같은 공개 지표는 외부 검증이 가능하지만, 자체 벤치마크는 커뮤니티 독립 검증을 지켜본 후 판단하는 것이 바람직하다.

## 한 줄 요약 — 이것만 기억하면 된다

**M2.5는 프론티어급 코딩 성능을 1/10 가격에 제공하며 "비용 대비 성능"을 새로운 경쟁 기준으로 만들었다. 단, 자체 벤치마크 비중이 높으므로 실제 워크플로에서 직접 검증하는 것이 최선이다.**
