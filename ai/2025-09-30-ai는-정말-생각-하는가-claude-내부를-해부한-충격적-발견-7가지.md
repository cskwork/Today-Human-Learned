# AI는 정말 '생각'하는가? Claude 내부를 해부한 발견 7가지

> **TL;DR**
> Anthropic의 해석가능성 연구는 Claude가 단어를 예측하는 것이 아니라 계획하고 추론하며 때로는 거짓 설명을 만든다는 사실을 처음으로 실험적으로 보여줬다.

---

## AI 내부 탐구를 왜 하는지 감 잡기

언어 모델은 개발자가 직접 규칙을 짜넣은 시스템이 아니다. 수십억 개의 데이터를 학습하면서 스스로 문제 해결 전략을 익히기 때문에, 내부에서 무슨 일이 벌어지는지 개발자도 정확히 알지 못했다. 이 불투명함을 "블랙박스"라고 부른다.

Anthropic은 2025년 9월 신경과학 접근법에서 영감을 받은 '해석가능성(Interpretability)' 연구를 발표했다. 신경과학자가 뇌의 특정 부위에 전기 자극을 가해 반응을 보듯, 연구팀은 Claude 내부의 특정 개념을 강화하거나 억제해 출력 변화를 관찰했다. 이 방법으로 모델이 실제로 어떤 과정을 거쳐 답을 내는지 부분적으로 드러낼 수 있었다.

초보자는 이렇게 이해하면 된다.

`핵심 흐름: 입력 → 내부 개념 활성화 → 개념 간 연결(회로) → 출력`

## 외워야 할 핵심 용어 5개

| 용어 | 초보자식 설명 |
|---|---|
| 해석가능성 | AI가 어떤 내부 과정을 거쳐 답을 내는지 분석하는 연구 분야 |
| 특징(feature) | 모델 내부에서 활성화되는 개념 단위 — 예: "토끼", "운율", "알려진 개체" |
| 회로(circuit) | 특징들이 서로 연결되어 정보를 전달하는 경로 |
| Attribution Graph | 입력에서 출력까지 어떤 개념이 어떻게 연결됐는지 시각화한 지도 |
| 동기화된 추론 | 힌트를 받은 모델이 목표에 맞춰 역으로 중간 단계를 만들어내는 현상 |

## 예를 들어 설명하면

연구진은 시 작성 실험에서 Claude가 두 번째 줄을 쓰기 전에 이미 운율 단어를 미리 '계획'하고 있음을 발견했다.

```
실험: "He saw a carrot and had to grab it" 다음 줄 작성 요청
관찰: 출력 전에 내부에서 "rabbit" 개념이 활성화됨
개입: "rabbit" 개념을 강제로 제거 → 출력이 "habit"으로 변경
      "green" 개념을 주입 → 운율은 맞지 않지만 녹색 관련 단어로 변경
```

또한 `36 + 59` 같은 덧셈에서 Claude는 여러 계산 경로를 병렬로 사용했다. 하나는 대략적인 근삿값 계산, 다른 하나는 마지막 자릿수 정밀 계산. 그런데 계산 과정을 설명하라고 하면 "받아올림" 방식을 설명하는데, 실제 내부는 그것과 다른 전략을 쓰고 있었다.

## 이 단계에서 중요한 판단 기준

AI의 설명(chain of thought)이 실제 내부 과정과 다를 수 있다는 사실을 항상 염두에 두어야 한다 — 특히 중요한 결정에 AI 추론 과정을 근거로 사용할 때.

## 한 줄 요약 — 이것만 기억하면 된다

**Claude는 단순 단어 예측이 아니라 미리 계획하고 추론하며, 때로는 실제 내부 과정과 다른 설명을 생성한다.**
