# 나노바나나 = Gemini 2.5 Flash Image

> **TL;DR**
> 구글이 공개한 Gemini 2.5 Flash Image(별칭 '나노바나나')는 이미지 생성과 편집을 하나의 모델로 처리하며, 캐릭터 일관성·부분 편집·다중 합성을 API 한 번 호출로 구현한다.

---

## Gemini 2.5 Flash Image를 왜 쓰는지 감 잡기

기존 이미지 AI는 생성과 편집이 분리된 경우가 많았다. 이미지를 만든 후 배경만 바꾸거나 특정 인물을 다른 장면에 유지하려면 별도 툴을 써야 했다. Gemini 2.5 Flash Image는 이 두 작업을 단일 모델로 처리한다. 개발자는 Gemini API, Google AI Studio, Vertex AI 중 하나를 통해 바로 사용할 수 있고, 이미지 한 장 생성 비용은 약 $0.039다.

초보자는 처음에 이렇게 이해하면 된다.

`핵심 흐름: 원본 이미지(선택) + 텍스트 프롬프트 → 생성/편집된 이미지 + SynthID 워터마크`

## 외워야 할 핵심 용어 5개

| 용어 | 초보자식 설명 |
|---|---|
| Gemini 2.5 Flash Image | 구글이 2025년 8월 공개한 이미지 생성·편집 통합 모델. 모델 ID: gemini-2.5-flash-image-preview. |
| 캐릭터 일관성 | 같은 인물·캐릭터를 다양한 장면·각도에서 동일하게 유지하는 기능. |
| 부분 편집 | 이미지 전체를 재생성하지 않고, 지정한 영역(배경, 얼룩, 자세 등)만 수정하는 기능. |
| 다중 이미지 합성 | 여러 이미지를 입력으로 받아 하나로 자연스럽게 합치는 기능. |
| SynthID | 구글이 삽입하는 보이지 않는 AI 생성 워터마크. 배포 전 정책 확인이 필요하다. |

## 예를 들어 설명하면

아래 세 가지 프롬프트 유형이 이 모델의 핵심 사용 패턴을 보여준다.

```
# 부분 편집 — 인물은 유지, 배경만 교체
"인물은 그대로 두고 배경을 카페 내부로 바꿔줘. 자연광 느낌으로."

# 다중 합성 — 두 이미지를 합쳐 물리적으로 자연스럽게
"이 두 사진을 합쳐 제품 A를 사진 B의 책상 위에 자연스럽게 올려줘. 그림자도 맞춰."

# 캐릭터 일관성 — 동일 캐릭터로 계절별 변형
"캐릭터는 동일하게 유지하고, 봄/여름/가을/겨울 분위기의 포스터 4종으로 만들어줘."
```

빠른 테스트는 Google AI Studio의 템플릿 앱(사진 편집/캐릭터 일관성/다중 합성)에서 시작하면 좋다.

## 이 단계에서 중요한 판단 기준

이미지를 전체 재생성할지, 부분 편집할지를 먼저 결정한다. 인물·캐릭터가 고정된 상태에서 배경·소품만 바꿔야 한다면 전체 재생성보다 부분 편집 지시가 비용과 품질 모두에서 유리하다.

## 한 줄 요약 — 이것만 기억하면 된다

**Gemini 2.5 Flash Image는 생성과 편집을 하나의 API 호출로 처리하는 통합 이미지 모델이다.**
