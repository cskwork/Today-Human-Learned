# Qwen3.6-35B-A3B — 3B만 켜도 85점대? MoE로 최상급 성능을 내다

> **TL;DR**
> Qwen3.6-35B-A3B는 전체 35B 파라미터 중 토큰 처리 시 3B만 활성화해, 소비자 GPU에서도 MMLU-Pro 85.2점을 달성하는 MoE 모델이다.

---

## Qwen3.6-35B-A3B를 왜 쓰는지 감 잡기

기존 조밀 모델(Dense)은 총 파라미터 수가 곧 추론 비용이었다. 32B 모델을 쓰려면 32B어치 VRAM과 연산을 토큰마다 소비해야 했다. MoE(Mixture of Experts, 전문가 혼합)는 이 구조를 바꾼다. 전문가 네트워크를 여러 개 두되, 입력마다 일부만 깨워 "저장 용량은 크게, 실행 비용은 작게" 분리한다. Qwen3.6-35B-A3B는 256개 전문가 중 매 토큰마다 8개만 활성화해, 실질적인 추론 비용을 3B 수준으로 낮춘다. 알리바바가 Apache-2.0 라이선스로 공개했으며, 단일 GPU에서 장문 처리나 에이전트 실험의 현실적인 선택지다.

초보자는 처음에 이렇게 이해하면 된다.

`핵심 흐름: 입력 토큰 → 라우터가 256개 전문가 중 8개 선택 → 선택된 전문가만 연산 → 출력`

## 외워야 할 핵심 용어 5개

| 용어 | 초보자식 설명 |
|---|---|
| MoE (Mixture of Experts) | 전문가 네트워크를 여러 개 두고 입력마다 일부만 활성화하는 구조다. 비용 절감이 핵심이다. |
| 활성 파라미터 (Activated Parameters) | 토큰 하나를 처리할 때 실제로 연산에 참여하는 파라미터 수다. 이 모델은 3B다. |
| 라우터 (Router) | 각 토큰을 어느 전문가에게 보낼지 결정하는 경량 네트워크다. |
| 공유 전문가 (Shared Expert) | 라우터 선택과 무관하게 모든 토큰이 항상 거치는 전문가다. 라우팅 실패 시 안전판 역할을 한다. |
| 하이브리드 어텐션 | Gated Attention(긴 의존성 정밀도)과 DeltaNet Linear Attention(장문 연산 효율)을 교차 배치한 구조다. |

## 예를 들어 설명하면

transformers로 모델을 로드하는 최소 예시다. 환경은 Python 3.11, transformers 4.50.0 이상이 필요하다.

```python
from transformers import AutoModelForCausalLM, AutoTokenizer

model_id = "Qwen/Qwen3.6-35B-A3B"
tokenizer = AutoTokenizer.from_pretrained(model_id)
model = AutoModelForCausalLM.from_pretrained(
    model_id,
    torch_dtype="auto",
    device_map="auto",
)

messages = [{"role": "user", "content": "MoE 아키텍처의 장점을 세 줄로 요약해줘."}]
inputs = tokenizer.apply_chat_template(
    messages, add_generation_prompt=True, return_tensors="pt"
).to(model.device)
outputs = model.generate(inputs, max_new_tokens=256)
print(tokenizer.decode(outputs[0][inputs.shape[-1]:], skip_special_tokens=True))
```

vLLM 기반 서버를 띄울 때는 `--enable-expert-parallel` 옵션을 함께 지정해야 전문가 병렬 처리가 활성화된다. 35B MoE지만 활성 파라미터가 3B이므로 24GB급 GPU에서도 4-bit 양자화 버전으로 구동된다. 단, 전문가 전체 가중치는 어딘가에 상주해야 하므로 저장소 여유 확인이 우선이다.

## 이 단계에서 중요한 판단 기준

단일 GPU에서 장문 RAG나 에이전트를 돌리고 싶다면 Qwen3.6-35B-A3B가 현시점 스윗스팟이고, 최고 정확도가 목표라면 총 파라미터 80B인 Next-80B-A3B를 고려한다.

## 한 줄 요약 — 이것만 기억하면 된다

**35B라는 숫자에 겁먹을 필요 없이, MoE 구조 덕분에 3B 수준의 추론 비용으로 최상급 벤치마크 점수를 소비자 GPU에서도 쓸 수 있다.**

## 나중에 더 깊게 들어가면

- 262K 네이티브 컨텍스트를 1M까지 확장하는 YaRN 설정 방법
- Qwen 세대별(3.5, 3.6, Next) 벤치마크 비교와 선택 기준
- 4-bit 양자화(GGUF) 버전으로 로컬 서버를 구성하는 방법
