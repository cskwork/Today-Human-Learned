# 고양이 HTML 게임 — Claude Sonnet 3.5로 구현하기

> **TL;DR**
> LLM에게 명확한 요구사항을 주면 완성된 브라우저 게임 코드를 한 번에 받을 수 있다.

---

## 이 주제를 왜 쓰는지 감 잡기

AI 코드 생성 도구가 실제로 얼마나 쓸 만한지 알아보는 가장 빠른 방법은 "작동하는 무언가"를 만들어보는 것이다. 고양이가 달리고 점프하는 브라우저 게임은 그 기준으로 딱 적당하다. HTML/CSS/JavaScript 세 가지를 동시에 써야 하고, 물리 시뮬레이션(중력, 이중 점프)과 애니메이션 루프까지 포함되기 때문에 "LLM이 단순 코드 조각만 만드는 게 아니다"라는 걸 확인하기에 좋다.

Sonnet 3.5에게 "고양이가 이중 점프 가능한 Canvas 게임을 HTML 단일 파일로 만들어줘"라고 요청하면 아래 흐름의 코드가 나온다.

`핵심 흐름: 사용자 입력(키보드) → 상태 갱신(위치·속도·중력) → Canvas 렌더링 → requestAnimationFrame 반복`

## 외워야 할 핵심 용어 5개

| 용어 | 초보자식 설명 |
|---|---|
| Canvas API | HTML `<canvas>` 태그에 픽셀 단위로 그림을 그리는 브라우저 내장 드로잉 도구 |
| requestAnimationFrame | 브라우저에게 "다음 화면 갱신 때 이 함수를 실행해줘"라고 예약하는 함수. 60fps 루프의 기반 |
| 중력(gravity) | 매 프레임마다 velocityY에 더해지는 작은 값. 이 값이 없으면 고양이가 허공에 떠 있다 |
| 이중 점프(double jump) | 공중에 있는 동안 한 번 더 점프를 허용하는 상태 플래그 처리 |
| 벡터 변환(ctx.scale + ctx.translate) | 고양이를 좌우 반전하거나 위치를 이동시킬 때 좌표계 자체를 바꾸는 기법 |

## 예를 들어 설명하면

이중 점프 로직의 핵심은 `isJumping`과 `doubleJumped` 두 플래그다.

```javascript
if (keys.ArrowUp && !keys.ArrowUpPressed) {
    if (!cat.isJumping) {
        cat.velocityY = -cat.jumpForce;  // 첫 번째 점프
        cat.isJumping = true;
        cat.doubleJumped = false;
    } else if (!cat.doubleJumped) {
        cat.velocityY = -cat.jumpForce;  // 두 번째 점프
        cat.doubleJumped = true;
    }
    keys.ArrowUpPressed = true;  // 키를 누른 채로 있어도 한 번만 처리
}
```

`ArrowUpPressed`는 키를 계속 누르고 있을 때 점프가 반복 실행되는 걸 막는다. 키를 떼는 순간 `keyup` 이벤트에서 이 플래그를 초기화한다.

## 이 단계에서 중요한 판단 기준

LLM 생성 코드를 바로 쓰기 전에 "게임 루프가 requestAnimationFrame 기반인지, setInterval 기반인지" 확인하라. setInterval은 탭이 비활성화되어도 실행돼 CPU를 낭비하고 프레임 타이밍이 어긋난다.

## 한 줄 요약 — 이것만 기억하면 된다

**requestAnimationFrame + 상태 플래그 두 개로 이중 점프 물리를 완성한다.**

## 나중에 더 깊게 들어가면

- 충돌 감지(AABB)로 발판 위에 착지하는 플랫포머 구조
- Sprite sheet를 이용한 프레임 애니메이션
- LLM 프롬프트 엔지니어링 — 요구사항을 어떻게 써야 코드 품질이 올라가는지
