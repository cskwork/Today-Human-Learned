# MCP와 코드 실행: 더 효율적인 에이전트 도구 사용

> **TL;DR**
> 에이전트가 MCP 도구를 직접 호출하면 토큰이 폭발한다. 도구를 코드 API로 제공하고 실행 환경에서 처리하면 토큰을 98% 줄일 수 있다.

---

## MCP와 코드 실행을 왜 쓰는지 감 잡기

MCP(Model Context Protocol)는 AI 에이전트가 외부 시스템(Google Drive, Salesforce, Slack 등)에 연결하는 표준 방식이다. 연결 자체는 편리하지만, 도구 수가 늘어나면 심각한 비용 문제가 생긴다.

현재 대부분의 MCP 클라이언트는 연결된 도구의 정의 전체를 AI 컨텍스트(기억 공간)에 미리 올린다. GitHub 35개 도구가 26K 토큰, Slack 11개 도구가 21K 토큰을 차지한다. 50개 도구만 연결해도 대화를 시작하기 전에 이미 수만 개의 토큰이 사라진다.

중간 결과도 문제다. AI가 Google Drive에서 문서를 가져와 Salesforce에 저장하는 경우, 그 문서 전체가 AI를 거쳐 다시 다음 도구로 넘어간다. 2시간짜리 회의록이면 50,000 토큰이 두 번 흐른다.

해법은 MCP 도구를 코드 API로 제공하는 것이다. 에이전트가 코드를 작성하면, 중간 처리는 실행 환경에서 이루어지고 최종 결과만 AI에게 전달된다.

초보자는 처음에 이렇게 이해하면 된다.

`핵심 흐름: MCP 서버 → 코드 파일로 변환 → 에이전트가 코드 작성 → 실행 환경에서 처리 → 결과만 반환`

## 외워야 할 핵심 용어 5개

| 용어 | 초보자식 설명 |
|---|---|
| 컨텍스트 윈도우 | AI가 한 번에 기억할 수 있는 텍스트 분량 — 이걸 넘으면 오래된 내용을 잊는다 |
| 도구 정의 | AI에게 "이 도구는 이런 파라미터를 받고 이런 결과를 돌려준다"고 설명하는 스키마 |
| 점진적 공개 | 모든 도구 정의를 처음부터 올리지 않고, 필요할 때 찾아 로드하는 방식 |
| PII 토큰화 | 이메일, 전화번호 같은 개인정보를 임시 토큰으로 바꿔 AI 컨텍스트를 통과시키는 기법 |
| 코드 실행 환경 | 에이전트가 작성한 코드를 안전하게 실행하는 격리된 공간 |

## 예를 들어 설명하면

Google Drive 문서를 Salesforce에 옮기는 작업을 두 방식으로 비교한다.

직접 도구 호출 방식에서는 문서 전체가 AI 컨텍스트를 통과한다.

```
TOOL CALL: gdrive.getDocument(documentId: "abc123")
    → 전체 녹취록 텍스트 (컨텍스트에 로드됨)

TOOL CALL: salesforce.updateRecord(data: { Notes: "전체 녹취록 텍스트..." })
    (AI가 전체 텍스트를 다시 컨텍스트에 작성해야 함)
```

코드 실행 방식에서는 중간 데이터가 코드 안에서 처리된다.

```typescript
import * as gdrive from './servers/google-drive';
import * as salesforce from './servers/salesforce';

const transcript = (await gdrive.getDocument({ documentId: 'abc123' })).content;
await salesforce.updateRecord({
  objectType: 'SalesMeeting',
  recordId: '00Q5f000001abcXYZ',
  data: { Notes: transcript }
});
```

문서는 코드 안에서 바로 전달된다. AI 컨텍스트를 거치지 않는다. 토큰 사용량이 150,000개에서 2,000개로 줄어든다(98.7% 절감).

## 이 단계에서 중요한 판단 기준

연결된 MCP 도구가 10개를 넘거나 중간 결과가 크다면, 직접 도구 호출 대신 코드 API 방식으로 전환해야 비용과 속도 두 가지를 동시에 잡을 수 있다.

## 한 줄 요약 — 이것만 기억하면 된다

**도구를 코드 API로 감싸면 AI가 중간 데이터를 건드리지 않아 토큰을 극적으로 아낄 수 있다.**

## 나중에 더 깊게 들어가면

- `search_tools` 도구를 서버에 추가해 에이전트가 필요한 도구만 동적으로 로드하는 방법
- 코드 실행 환경의 샌드박싱, 리소스 제한, 보안 설정
- PII 자동 토큰화를 MCP 클라이언트 레이어에서 구현하는 방법
