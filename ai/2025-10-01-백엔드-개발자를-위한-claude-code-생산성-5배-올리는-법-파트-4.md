# 백엔드 개발자를 위한 Claude Code 생산성 올리는 법 — 파트 4

> **TL;DR**
> RAG 기반 시맨틱 검색, 팀 공유 Slash Commands, Hooks 기반 품질 게이트, Git Worktree 병렬 세션을 조합하면 Claude Code가 개인 도구를 넘어 팀 전체의 개발 인프라가 된다.

---

## 팀 협업 수준의 Claude Code를 왜 배우는지 감 잡기

개인 생산성 도구로 Claude Code를 쓰다 보면 다음 질문이 생긴다. "팀원도 같은 방식으로 쓰고 있는가?" 그렇지 않으면 코드 리뷰 방식이 사람마다 다르고, 마이그레이션 절차가 구두로만 전달되며, 좋은 프롬프트 패턴이 개인 노트에만 남는다.

파트 4는 Claude Code 설정을 팀 레포지토리에 커밋하고, 품질 검사를 자동화하며, 컨텍스트 손실 없이 여러 작업을 병렬 처리하는 방법을 다룬다. 이 시점부터 Claude Code는 개인 편의 도구가 아니라 팀이 공유하는 개발 표준이 된다.

초보자는 이렇게 이해하면 된다.

`핵심 흐름: 팀 설정 파일 작성 → Git 커밋 → 팀원 클론 시 자동 적용 → 품질 게이트 자동 실행`

## 외워야 할 핵심 용어 5개

| 용어 | 초보자식 설명 |
|---|---|
| 시맨틱 검색(RAG) | 정확한 파일명 없이 "사용자 인증 관련 로직"처럼 의미로 코드를 찾는 방식; 벡터 데이터베이스에 코드를 인덱싱해서 가능 |
| Slash Commands | .claude/commands/ 디렉토리에 저장하는 재사용 가능한 프롬프트 파일; Git으로 팀 전체가 공유 가능 |
| Hooks | Claude가 파일을 수정하거나 커밋하기 전/후에 자동 실행되는 쉘 명령; .claude/settings.json에 정의 |
| Exit code 2 | Hook 스크립트에서 오류 시 사용하는 종료 코드; 이 코드를 받으면 Claude가 자동으로 문제를 수정하려 시도 |
| Git Worktree | 동일한 레포지토리의 서로 다른 브랜치를 별도 디렉토리에서 동시에 체크아웃하는 Git 기능 |

## 예를 들어 설명하면

팀이 공유하는 DB 마이그레이션 Slash Command 예시:

```markdown
# .claude/commands/db-migration.md
---
description: 안전한 데이터베이스 마이그레이션 실행
argument-hint: <migration-name>
---

# 데이터베이스 마이그레이션: $ARGUMENTS

다음 순서로 실행:
1. 백업 먼저 실행: npm run db:backup
2. 마이그레이션 생성 (SQL만, 아직 적용 안 함)
3. 생성된 SQL에서 DROP 문과 데이터 손실 가능성 확인
4. 테스트 DB에서 먼저 실행
5. 승인 후 프로덕션 적용
```

Git Worktree로 기능 개발과 긴급 패치를 컨텍스트 손실 없이 병렬 처리:

```bash
# 기능 개발 Worktree 생성
git worktree add ../api-server-feat-notifications feat/notifications

# 핫픽스 Worktree 별도 생성
git worktree add ../api-server-hotfix hotfix/login-timeout

# 각각 독립적인 Claude 세션으로 실행
cd ../api-server-feat-notifications && claude   # 터미널 1
cd ../api-server-hotfix && claude               # 터미널 2
```

## 이 단계에서 중요한 판단 기준

.claude/commands/와 .claude/settings.json을 Git에 커밋하는 순간 팀 전체가 동일한 자동화를 쓰게 된다 — 설정 전에 팀이 합의한 컨벤션을 먼저 정의하지 않으면 나중에 충돌이 생긴다.

## 한 줄 요약 — 이것만 기억하면 된다

**Claude Code 설정 파일을 Git에 커밋하면 개인 도구가 팀 인프라가 되고, Hooks가 품질 게이트를 자동화하며, Worktree가 병렬 작업의 컨텍스트를 보존한다.**

## 나중에 더 깊게 들어가면

- 벡터 데이터베이스를 로컬에서 Docker로 실행해 코드 시맨틱 검색을 무료로 구축하는 법
- GitHub Actions에 Claude Headless 모드를 통합해 PR 자동 리뷰를 구성하는 방법
- 조직 단위 백엔드 프로젝트 템플릿 구조 설계
