# 기업 법무팀의 AI 도입: Anthropic 사례로 보는 실전 워크플로우

> **TL;DR**
> 법무팀 AI 도입은 코딩 능력이 아니라 업무 프로세스 분석 능력이 좌우한다. 가장 지루한 반복 업무부터 자동화하는 것이 성공 전략이다.

---

## 법무팀이 AI를 왜 도입하는지 감 잡기

법무팀은 반복 업무가 많다. 마케팅 자료가 완성될 때마다 법적 리스크를 검토하고, 계약서마다 표준 조항을 확인하고, 이해충돌 정책을 대조한다. 이 과정은 전문성이 필요하지만, 동시에 체크리스트 성격이 강하다.

AI는 이런 1차 스크리닝을 대신 처리하기에 적합하다. Anthropic 법무팀 담당자는 "코딩을 전혀 몰라도 자연어 대화만으로 워크플로우를 구축했다"고 말한다. 기술이 아니라 어떤 업무를 자동화할지 판단하는 것이 핵심이다.

초보자는 처음에 이렇게 이해하면 된다.

`핵심 흐름: 반복 업무 식별 → 검토 프레임워크 정의 → AI 1차 스크리닝 → 사람이 최종 판단`

## 외워야 할 핵심 용어 5개

| 용어 | 초보자식 설명 |
|---|---|
| Human-in-the-Loop | AI가 1차 처리하고 사람이 최종 검토하는 구조. AI를 자율 판단자가 아닌 보조 도구로 사용한다. |
| 검토 프레임워크 | AI에게 "무엇을 기준으로 검토할지"를 알려주는 체크리스트. 이게 없으면 AI 결과가 일관되지 않는다. |
| 리스크 수준 분류 | 이슈를 Low / Medium / High로 나눠 법무 담당자가 우선순위를 빠르게 파악하게 하는 방식 |
| 워크플로우 연동 | AI 도구를 기존 업무 흐름(Slack, 이메일 등)에 붙여 사용 장벽을 낮추는 것 |
| 환각 (Hallucination) | AI가 사실이 아닌 내용을 그럴듯하게 만들어내는 현상. 법무 영역에서 특히 위험하다. |

## 예를 들어 설명하면

Anthropic 법무팀의 마케팅 자료 검토 자동화는 이렇게 작동한다.

```
기존: 마케팅팀 → 법무팀에 검토 요청 → 담당자가 처음부터 끝까지 읽음 → 이슈 목록 작성

자동화 이후:
1. 마케팅 담당자가 검토 도구에 콘텐츠 붙여넣기
2. 'Analyze Content' 클릭
3. AI가 사전 정의된 프레임워크로 분석
   - 사실 정확성 / 보안 관련 주장 / 제3자 콘텐츠 권리 / 파트너십 공개 여부
4. 이슈 목록 + 리스크 수준(Low/Medium/High) 자동 생성
5. 법무팀 전달용 메시지 자동 작성
6. 법무 담당자는 분류된 이슈에 대해 전문적 판단만 내림
```

핵심은 AI가 1차 분류를 담당하고, 최종 판단은 반드시 사람이 한다는 것이다.

## 이 단계에서 중요한 판단 기준

AI 출력을 검토 프레임워크 없이 사용하면 결과가 매번 달라진다. "AI가 무엇을 확인해야 하는지"를 먼저 문서로 정의한 뒤에 도구를 구축한다.

## 한 줄 요약 — 이것만 기억하면 된다

**법무 AI 도입은 가장 반복적인 업무 하나를 골라 검토 기준을 명문화한 뒤, AI를 1차 처리자로 사람을 최종 판단자로 역할을 분리하는 것에서 시작한다.**

## 나중에 더 깊게 들어가면

- 계약서 조항 자동 비교 및 표준 대비 변경사항 탐지 방법
- 법무 AI 출력의 정확도를 평가하는 지표 설계
- 민감 법률 정보를 AI에 전달할 때 보안 처리 방법
