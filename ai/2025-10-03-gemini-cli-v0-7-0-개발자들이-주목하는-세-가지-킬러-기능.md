# Gemini CLI v0.7.0, 개발자들이 주목하는 세 가지 킬러 기능

> **TL;DR**
> Gemini CLI v0.7.0은 터미널에서 이미지 생성, 멀티스텝 TODO 자동 추적, 커스텀 명령 체이닝을 가능하게 한 업데이트다.

---

## Gemini CLI를 왜 쓰는지 감 잡기

Gemini CLI는 구글이 오픈소스로 공개한 AI 에이전트로, 터미널에서 Gemini 모델을 직접 호출한다. 개인 구글 계정 기준 분당 60회, 하루 1,000회까지 무료로 쓸 수 있어 별도 API 비용 부담이 없다. v0.7.0 이전까지는 코딩 보조 역할에 머물렀다. 이번 업데이트는 이미지 편집, 작업 관리, CI/CD 자동화로 범위를 넓혔다.

초보자는 이렇게 이해하면 된다.

`핵심 흐름: 터미널 명령 → Gemini 모델 처리 → 결과 반환 (이미지/텍스트/작업 목록)`

## 외워야 할 핵심 용어 5개

| 용어 | 초보자식 설명 |
|---|---|
| MCP (Model Context Protocol) | AI가 외부 도구와 대화하는 표준 규격 — USB 규격처럼 모델과 도구를 꽂으면 바로 연결된다 |
| Extension (익스텐션) | 컨텍스트 파일, MCP 서버, 커스텀 명령을 묶은 플러그인 패키지 |
| Headless Mode | 사람이 개입하지 않고 CLI를 실행하는 방식 — CI/CD 파이프라인 자동화에 사용한다 |
| 커스텀 슬래시 명령 | `.toml` 파일로 정의한 재사용 프롬프트 — `/find-capital`, `/review-pr` 같은 형태 |
| SynthID | Google이 AI 생성 이미지에 자동 삽입하는 보이지 않는 워터마크 |

## 예를 들어 설명하면

아래는 커스텀 명령 두 개를 체인으로 연결하는 예시다. 첫 번째 명령의 결과를 두 번째 명령의 입력으로 파이프한다.

```toml
# ~/.gemini/commands/find-capital.toml
prompt="Please provide the capital city of {{args}}."

# ~/.gemini/commands/things-to-do.toml
prompt="Please provide fun things to do in the city of {{args}}."
```

```bash
gemini "/things-to-do $(gemini "/find-capital Estonia")"
```

같은 방식으로 PR 번호를 받아 diff를 추출한 뒤 리뷰 코멘트를 생성하는 코드 리뷰 자동화도 구성할 수 있다.

이미지 생성은 Nano Banana 익스텐션을 설치한 뒤 `/generate` 또는 `/edit` 명령으로 실행한다.

```bash
gemini extensions install https://github.com/gemini-cli-extensions/nanobanana
```

TODO 기능은 `settings.json`에 `"useWriteTodos": true`를 추가하면 활성화된다. 복잡한 작업을 요청하면 Gemini가 단계별 체크리스트를 자동 생성하고 진행 상황을 실시간으로 표시한다.

## 이 단계에서 중요한 판단 기준

익스텐션 설치 전 배포 주체가 신뢰할 수 있는 출처인지 확인하라 — 커스텀 명령과 MCP 서버는 로컬 파일 시스템과 외부 API에 접근할 수 있다.

## 한 줄 요약 — 이것만 기억하면 된다

**터미널 하나로 이미지 생성, 작업 추적, 워크플로 자동화를 무료로 연결할 수 있는 것이 Gemini CLI v0.7.0의 핵심이다.**

## 나중에 더 깊게 들어가면

- MCP 서버를 직접 만들어 Gemini CLI에 연결하는 방법
- Vertex AI 키를 사용해 팀 단위 대규모 요청을 처리하는 설정
- Headless 모드를 GitHub Actions 워크플로에 통합하는 실전 예시
