# Comet — 새로운 패러다임의 웹 브라우저

> **TL;DR**
> Comet은 Perplexity가 만든 AI 내장 브라우저로, 탭 전환 없이 자연어 명령 하나로 웹 작업을 실행한다.

---

## Comet을 왜 쓰는지 감 잡기

기존 브라우저는 사용자가 직접 탭을 열고, 정보를 찾고, 복사하고, 다른 앱으로 옮기는 과정을 모두 수행해야 한다. 이 과정에서 집중력이 분산되고 반복 작업이 쌓인다.

Comet은 "탭을 관리하는 도구"가 아니라 "사용자의 의도를 수행하는 에이전트"로 브라우저를 재정의한다. Perplexity의 검색 정확성과 AI 에이전트 기능을 결합해, 사용자가 말하면 브라우저가 직접 행동한다.

초보자는 처음에 이렇게 이해하면 된다.

`핵심 흐름: 사용자 의도 입력 → AI가 맥락 파악 → 브라우저가 직접 실행`

## 외워야 할 핵심 용어 5개

| 용어 | 초보자식 설명 |
|---|---|
| 에이전트 브라우저 | 단순 렌더링을 넘어 사용자 대신 작업을 수행하는 브라우저 유형. |
| Comet Assistant | Comet 내장 AI로, 검색·요약·작업 실행을 자연어로 처리하는 대화형 인터페이스. |
| 맥락 인식(Context Awareness) | 현재 보고 있는 페이지와 이전 행동을 기억해 연속적인 작업을 이어주는 능력. |
| 자동화 실행 | "이 정보를 메일로 보내줘"처럼 자연어 명령만으로 외부 서비스 연동 작업을 처리하는 기능. |
| 퍼플렉시티 정확성 | Perplexity 특유의 출처 기반 답변 방식. 환각(hallucination)을 줄이고 신뢰도를 높인다. |

## 예를 들어 설명하면

논문을 읽던 중 Comet Assistant에 "이 논문의 핵심 주장을 요약하고, 반박 관점 두 가지도 찾아줘"라고 입력하면 Comet은 현재 페이지 내용을 분석하고, 관련 문헌을 추가 검색해 결과를 한 화면에 정리한다. 사용자가 탭을 하나도 새로 열지 않아도 된다.

기존 방식과 비교하면 다음과 같다.

| 작업 | 기존 브라우저 | Comet |
|---|---|---|
| 정보 요약 | 탭 열기 → 읽기 → 복사 → 요약 앱으로 이동 | 한 문장 명령 |
| 가격 비교 | 사이트 여러 개 수동 탐색 | "더 빠른 배송처 찾아줘" 한 마디 |
| 메일 발송 | 내용 복사 → 메일 앱 이동 → 작성 | 명령 한 번 |

## 이 단계에서 중요한 판단 기준

Comet을 선택할 이유는 "정보 탐색과 행동 사이의 전환 비용"이 현재 워크플로의 병목인지 여부다. 단순 웹 서핑이라면 일반 브라우저로 충분하고, 연구·정보 처리·반복 웹 작업이 많다면 Comet이 효과적이다.

## 한 줄 요약 — 이것만 기억하면 된다

**Comet은 "검색 후 사용자가 행동"하는 구조를 "브라우저가 대신 행동"하는 구조로 바꾼 AI 에이전트 브라우저다.**

## 나중에 더 깊게 들어가면

- Comet의 개인화 메모리 기능과 데이터 프라이버시 정책
- 에이전트 브라우저가 기존 웹 자동화(Selenium, Playwright)와 다른 점
- Perplexity 검색 엔진의 출처 검증 메커니즘
