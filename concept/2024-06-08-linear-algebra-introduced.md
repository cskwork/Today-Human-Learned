# 선형대수 — AI와 데이터 과학의 수학적 기반

> **TL;DR**
> 선형대수는 벡터와 행렬을 다루는 수학 분야로, 데이터를 변환하고 연립방정식을 푸는 도구이며 머신러닝의 핵심 언어다.

---

## 선형대수를 왜 쓰는지 감 잡기

머신러닝 모델은 결국 숫자 배열을 다른 숫자 배열로 바꾸는 작업이다. 이미지 한 장은 수백만 개의 픽셀 값으로 이루어진 배열이고, 신경망의 각 레이어는 그 배열에 행렬 연산을 적용한다. 선형대수 없이는 이 변환을 표현할 언어가 없다.

물리, 공학, 컴퓨터 그래픽, 자연어 처리까지 모두 같은 수학 구조를 공유한다. 좌표를 돌리거나(회전), 늘리거나(스케일링), 투영하는 모든 작업이 행렬 곱셈 하나로 표현된다.

초보자는 처음에 이렇게 이해하면 된다.

`핵심 흐름: 스칼라 → 벡터 → 행렬 → 선형 변환 → 연립방정식 풀기`

## 외워야 할 핵심 용어 5개

| 용어 | 초보자식 설명 |
|---|---|
| 스칼라(Scalar) | 그냥 숫자 하나. 예: 3, -5, 0.7 |
| 벡터(Vector) | 순서가 있는 숫자 목록. 공간에서 방향과 크기를 가진 화살표로 생각하면 된다. 예: `[2, 3]` |
| 행렬(Matrix) | 숫자를 격자 형태로 배열한 것. 벡터에 적용해서 방향과 크기를 바꾸는 변환 도구다. |
| 선형 변환(Linear Transformation) | 벡터를 다른 벡터로 바꾸는 함수. 벡터 간 비율과 덧셈 관계를 유지한다. |
| 내적(Dot Product) | 두 벡터를 곱해 하나의 숫자를 얻는 연산. 두 벡터가 얼마나 같은 방향인지 나타낸다. |

## 예를 들어 설명하면

벡터 `[x, y]`를 90도 회전시키는 행렬 변환이다. 행렬을 벡터에 곱하면 회전된 좌표가 나온다.

```
회전 행렬 (90도):
| 0  -1 |   |x|   |-y|
| 1   0 | × |y| = | x|
```

입력 벡터 `[3, 1]`에 적용하면 결과는 `[-1, 3]`이 된다. 좌표가 90도 회전한 것이다. 신경망에서 각 레이어는 바로 이런 행렬 곱셈을 수천 번 반복한다. 가중치 행렬이 입력 벡터를 다음 레이어의 표현으로 변환한다.

## 이 단계에서 중요한 판단 기준

머신러닝 코드에서 이상한 결과가 나올 때, 먼저 행렬의 shape(차원 크기)부터 확인한다. 대부분의 버그는 차원 불일치에서 온다.

## 한 줄 요약 — 이것만 기억하면 된다

**데이터는 벡터고, 모델은 행렬이다. 선형대수는 그 둘 사이의 언어다.**

## 나중에 더 깊게 들어가면

- 행렬식(Determinant)과 역행렬(Inverse Matrix)
- 고유값(Eigenvalue)과 고유벡터(Eigenvector) — PCA의 수학적 기반
- 특이값 분해(SVD) — 추천 시스템과 데이터 압축에 사용
