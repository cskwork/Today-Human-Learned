# Bootstrap — 반응형 웹 개발을 위한 프론트엔드 프레임워크

> **TL;DR**
> Bootstrap은 미리 만들어진 CSS·JS 컴포넌트 묶음으로, HTML만 작성해도 화면 크기에 맞게 자동으로 레이아웃이 바뀌는 웹 페이지를 빠르게 완성할 수 있다.

---

## Bootstrap을 왜 쓰는지 감 잡기

웹 페이지를 처음 만들면 버튼 하나 예쁘게 만드는 데도 CSS를 수십 줄 써야 하고, 화면이 좁아질 때 레이아웃이 무너지지 않게 하려면 미디어 쿼리를 별도로 작성해야 한다. Bootstrap은 이런 반복 작업을 없애기 위해 트위터 팀이 만든 프레임워크다. HTML 태그에 클래스 이름만 붙이면 버튼, 내비게이션 바, 카드 같은 UI 요소가 바로 완성되고, 데스크탑·태블릿·모바일 모두에서 깔끔하게 보인다.

초보자는 처음에 이렇게 이해하면 된다.

`핵심 흐름: Bootstrap CSS 파일 로드 → HTML에 클래스 부여 → 브라우저가 자동으로 스타일 적용`

## 외워야 할 핵심 용어 5개

| 용어 | 초보자식 설명 |
|---|---|
| 반응형 디자인 | 화면 크기가 달라져도 레이아웃이 자동으로 조정되는 방식 |
| 그리드 시스템 | 페이지를 12개 열로 나누어 요소의 너비를 숫자로 지정하는 방법 |
| 컴포넌트 | 버튼·모달·내비게이션 바처럼 바로 가져다 쓸 수 있는 미리 만들어진 UI 조각 |
| 유틸리티 클래스 | `mt-3`, `text-center`처럼 한 가지 스타일만 담당하는 짧은 클래스 이름 |
| 모바일 우선 | 가장 작은 화면 기준으로 먼저 설계하고, 큰 화면으로 넓혀가는 설계 철학 |

## 예를 들어 설명하면

3단 레이아웃이 필요할 때 CSS를 직접 짜는 대신 Bootstrap 클래스로 해결할 수 있다.

```html
<div class="container">
  <div class="row">
    <div class="col-sm-4">왼쪽</div>
    <div class="col-sm-4">가운데</div>
    <div class="col-sm-4">오른쪽</div>
  </div>
</div>
```

`col-sm-4`는 "작은 화면(sm) 이상에서 12열 중 4열을 차지하라"는 뜻이다. 화면이 그보다 좁으면 세 칸이 자동으로 세로로 쌓인다. 버튼 하나를 파란색 기본 스타일로 만들고 싶다면 `<button class="btn btn-primary">` 한 줄로 끝난다.

## 이 단계에서 중요한 판단 기준

Bootstrap을 도입하면 개발 속도는 빨라지지만, 기본 스타일을 덮어쓰는 커스터마이징이 많아질수록 오히려 복잡해지므로 디자인 요구사항이 단순한 프로젝트에 가장 적합하다.

## 한 줄 요약 — 이것만 기억하면 된다

**클래스 이름만 올바르게 붙이면 반응형 UI를 CSS 없이도 완성할 수 있는 것이 Bootstrap의 핵심 가치다.**
