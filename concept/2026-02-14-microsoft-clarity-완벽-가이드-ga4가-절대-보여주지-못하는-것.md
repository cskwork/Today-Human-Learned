# Microsoft Clarity — GA4가 절대 보여주지 못하는 것

> **TL;DR**
> Microsoft Clarity는 히트맵과 세션 리플레이를 무제한 무료로 제공하는 행동 분석 도구로, GA4가 "무엇이 일어났는지" 보여줄 때 Clarity는 "왜 일어났는지"를 눈으로 보여준다.

---

## 이 주제를 왜 쓰는지 감 잡기

Google Analytics 대시보드에서 이탈률 75%를 봤다고 해서, 사용자가 어디서 막혔는지는 알 수 없다. 어떤 버튼을 클릭했는데 아무 반응이 없어서 떠났는지, 스크롤이 절반쯤에서 멈췄는지 — 숫자만으로는 진단이 안 된다.

Microsoft Clarity는 이 "왜"를 시각적으로 보여주는 도구다. Hotjar 같은 유사 도구는 유료지만, Clarity는 트래픽 제한 없이 완전 무료다. 2020년 출시 이후 "무료인데 이래도 되나 싶은 도구"로 자리잡았다.

`핵심 흐름: GA4로 이상 감지 → Clarity로 원인 시각화 → 세션 리플레이로 정확한 장면 확인`

## 외워야 할 핵심 용어 5개

| 용어 | 초보자식 설명 |
|---|---|
| 세션 리플레이 | 실제 방문자의 마우스 움직임, 클릭, 스크롤을 영상처럼 재생하는 기능 |
| 히트맵 | 사용자가 어디를 클릭하고 어디서 스크롤을 멈췄는지 색상으로 보여주는 지도 |
| Rage Click | 같은 지점을 빠르게 반복 클릭하는 행동 — 사용자가 화가 났거나 반응이 없다는 신호 |
| Dead Click | 클릭했지만 아무 반응이 없었던 요소 — UI 버그나 오해를 유발하는 디자인의 신호 |
| Clarity Copilot | 최대 250개 세션 녹화를 AI가 한꺼번에 분석해 공통 문제를 자연어로 요약해주는 기능 |

## 예를 들어 설명하면

한 서비스가 "무료 체험 시작" 버튼에 Rage Click이 집중되는 것을 Clarity에서 발견했다. 세션 리플레이로 확인하니, 버튼 클릭 후 시각적 피드백이 나타나기까지 1.5초 지연이 있었다. 로딩 메시지를 추가하자 Rage Click이 사라지고 전환율이 개선됐다.

이런 진단이 가능한 이유는 Clarity가 제공하는 히트맵 유형이 다양하기 때문이다.

| 히트맵 유형 | 보여주는 것 |
|---|---|
| Click Map | 클릭이 집중된 영역 |
| Scroll Map | 스크롤이 어디까지 내려갔는지 |
| Dead Click Map | 클릭했지만 반응 없던 곳 |
| Rage Click Map | 분노의 연속 클릭 발생 지점 |

## 이 단계에서 중요한 판단 기준

Clarity가 모든 상황에 맞지는 않는다. Microsoft는 수집된 익명화 데이터를 머신러닝과 광고 서비스에 활용할 수 있으므로, 의료·금융·정부 관련 서비스에서는 도입 전 프라이버시 정책을 반드시 검토해야 한다.

## 한 줄 요약 — 이것만 기억하면 된다

**GA4로 숫자를 보고, Clarity로 그 숫자 뒤의 사용자 행동을 눈으로 확인한다.**

## 나중에 더 깊게 들어가면

- GA4와 Clarity 연동 후 세션 녹화 URL을 GA4 탐색 보고서에서 바로 여는 방법
- EEA/UK 방문자 대상 쿠키 동의 모드(Consent Mode) 설정 요건 (2025년 10월 31일부터 필수)
- Clarity vs Hotjar — 설문·피드백·팀 협업 워크플로가 필요한 경우에는 Hotjar가 적합한 이유
