# CSV 파일 병합 — 여러 파일을 하나로 합치기

> **TL;DR**
> 헤더가 같은 여러 CSV 파일은 첫 파일을 복사한 뒤 나머지 파일의 헤더 행을 건너뛰고 이어붙이면 된다.

---

## CSV 병합을 왜 해야 하는지 감 잡기

데이터 내보내기 도구는 용량 제한 때문에 같은 형식의 파일을 여러 개로 나눠 제공하는 경우가 많다. 분석 도구에 올리거나 SQL로 읽으려면 하나의 파일이 필요하다.

스프레드시트로 일일이 열어 복사하는 방법은 파일 수가 늘수록 비효율적이고 실수가 생긴다. 터미널 명령 한 줄이면 160만 행도 수초 안에 처리된다.

초보자는 처음에 이렇게 이해하면 된다.

`핵심 흐름: 첫 파일 복사 (헤더 포함) → 나머지 파일 헤더 제거 후 추가 → 행 수 검증`

## 외워야 할 핵심 용어 5개

| 용어 | 초보자식 설명 |
|---|---|
| 헤더 행 | CSV 파일 첫 번째 줄. 각 열의 이름을 담고 있다. |
| `tail -n +2` | 파일의 2번째 줄부터 끝까지 출력하는 명령. 헤더 한 줄을 건너뛴다. |
| `>>` (리다이렉트) | 출력 내용을 파일 끝에 이어 붙인다. `>` 는 덮어쓴다. |
| `wc -l` | 파일의 행 수를 센다. 병합 결과 검증에 쓴다. |
| for 루프 | `{2..15}` 처럼 범위를 지정해 반복 작업을 자동화하는 셸 문법. |

## 예를 들어 설명하면

파일명 패턴이 `data.csv`, `data_2.csv`, ..., `data_15.csv`인 경우를 기준으로 한다.

```bash
# 1단계: 첫 번째 파일을 결과 파일로 복사 (헤더 포함)
cp "data.csv" "data_merged.csv"

# 2단계: 나머지 파일들을 헤더 없이 이어붙이기
for i in {2..15}; do
    tail -n +2 "data_${i}.csv" >> "data_merged.csv"
done

# 3단계: 검증 — 개별 행 수 합계와 병합 결과 비교
for i in {2..15}; do
    echo "data_${i}.csv: $(wc -l < "data_${i}.csv")"
done
echo "merged: $(wc -l < "data_merged.csv")"
```

병합 결과의 행 수는 전체 파일 행 수의 합에서 중복 헤더 수(파일 수 - 1)를 뺀 값과 같아야 한다. 이 숫자가 맞으면 데이터 누락 없이 병합된 것이다.

## 이 단계에서 중요한 판단 기준

모든 파일의 컬럼 순서와 인코딩이 동일해야 한다. 하나라도 다르면 데이터가 뒤섞인다. 병합 전에 `head -1 data_2.csv`로 헤더를 확인한다.

## 한 줄 요약 — 이것만 기억하면 된다

**`cp` 로 헤더를 확보하고, `tail -n +2` 와 `>>` 를 루프로 돌리면 어떤 크기의 CSV도 메모리 걱정 없이 병합된다.**
