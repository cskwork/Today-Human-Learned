# 링크드 리스트 — 포인터로 연결된 체인 구조

> **TL;DR**
> 링크드 리스트는 각 노드가 다음 노드의 주소를 저장하는 구조로, 중간 삽입·삭제가 배열보다 유리하지만 임의 접근은 불가하다.

---

## 링크드 리스트를 왜 쓰는지 감 잡기

배열은 칸이 메모리에 붙어 있어서 삽입·삭제 시 데이터를 밀어야 한다. 반면 링크드 리스트는 각 데이터가 메모리 어디에든 흩어져 있고, "다음 데이터의 주소"만 들고 있다. 클립 여러 개를 체인처럼 연결한 것과 같다. 클립 사이에 하나를 끼워 넣거나 빼는 건 쉽지만, 열 번째 클립을 바로 집는 건 첫 번째부터 세어야 한다.

링크드 리스트는 삽입·삭제가 잦고 크기가 동적으로 변하는 상황에서 배열의 대안으로 쓰인다. 운영체제의 메모리 관리, 텍스트 편집기의 실행 취소 기능 등이 대표 사례다.

`핵심 흐름: Head 노드 접근 → 포인터를 따라 이동 → 목표 노드 도달 → 연산 수행`

## 외워야 할 핵심 용어 5개

| 용어 | 초보자식 설명 |
|---|---|
| 노드(Node) | 데이터와 다음 노드의 주소를 함께 저장하는 기본 단위. |
| Head | 리스트의 첫 번째 노드. 여기서부터 순회가 시작된다. |
| 포인터(Pointer) | 다음 노드가 메모리 어디에 있는지 가리키는 참조값. |
| 단방향 링크드 리스트 | 각 노드가 다음 노드만 가리키는 구조. 역방향 이동 불가. |
| 이중 링크드 리스트 | 각 노드가 이전 노드와 다음 노드 둘 다 가리키는 구조. 역방향 이동 가능. |

## 예를 들어 설명하면

Python으로 단방향 링크드 리스트를 만들고 순회하는 최소 예제다.

```python
class Node:
    def __init__(self, data):
        self.data = data
        self.next = None   # 다음 노드 주소. 아직 없으면 None.

class LinkedList:
    def __init__(self):
        self.head = None

    def append(self, data):
        new_node = Node(data)
        if not self.head:
            self.head = new_node
            return
        current = self.head
        while current.next:      # 마지막 노드까지 이동
            current = current.next
        current.next = new_node  # 마지막 노드가 새 노드를 가리킴

ll = LinkedList()
ll.append(1)
ll.append(2)
ll.append(3)
# 메모리: 1 -> 2 -> 3 -> None
```

노드 사이에 삽입할 때는 앞 노드의 `next`를 새 노드로, 새 노드의 `next`를 기존 다음 노드로 바꾸기만 하면 된다. 데이터를 밀 필요가 없다.

## 이 단계에서 중요한 판단 기준

"삽입·삭제가 빈번하면 링크드 리스트, 특정 인덱스에 자주 접근해야 하면 배열을 선택한다."

## 한 줄 요약 — 이것만 기억하면 된다

**링크드 리스트는 포인터로 노드를 연결해 중간 삽입·삭제가 O(1)이지만, 임의 접근은 O(N)이다.**

## 나중에 더 깊게 들어가면

- 원형 링크드 리스트(Circular Linked List): 마지막 노드가 Head를 가리키는 구조
- 링크드 리스트로 스택·큐 구현하기
- 링크드 리스트의 중간 노드를 O(N) 없이 찾는 투 포인터 기법
