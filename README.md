# Today Human Learned (THL)

> 매일 마주친 문제·도구·개념을 **주제별·날짜별**로 정리하는 학습 저장소.
> 한 주제를 처음 배우는 사람이 '아, 이런 거구나' 하고 감을 잡을 수 있도록 — 파인만 스타일로 짧게.

## 구조

```text
.
├── README.md          # 이 파일 (전체 인덱스)
├── ai/                # 주제 디렉터리
├── java/
├── ...
└── <topic>/
    └── YYYY-MM-DD-<slug>.md
```

- 파일명 규칙: `YYYY-MM-DD-<kebab-slug>.md`
- 글 하나는 **하나의 주제만** 다룬다. 60~120줄을 목표.
- 형식: **TL;DR → 왜 쓰는지 → 핵심 흐름 → 핵심 용어 5개 → 예시 → 판단 기준 → 한 줄 요약 → 다음에 배울 내용**.

## 글 작성 원칙

1. **TL;DR을 맨 위에** — 한 줄에 결론이 보여야 한다.
2. **"왜 그렇게 되는지"를 적는다** — 명령어 모음집은 검색하면 나온다.
3. **이모지·블로그 인사 금지** — 정보 밀도가 떨어진다.
4. **회사·고객·내부 시스템 이름은 일반화한다.**
