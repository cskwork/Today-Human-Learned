> **TL;DR**
> 스타 그래프에서 중심 노드는 모든 간선에 공통으로 등장하므로, 첫 두 간선만 비교하면 O(1)에 찾을 수 있다.

---

## 이 문제를 왜 푸는지 감 잡기

스타 그래프(star graph)는 하나의 허브 노드가 나머지 모든 노드와 연결된 구조다. 실제로 항공 노선 허브, 인터넷 라우터 연결 구조, 소셜 네트워크의 인플루언서 탐색 같은 상황에서 이 패턴이 자주 등장한다.

n개의 노드가 있을 때 간선(edge) 목록이 주어지고, 그 중 중심(center) 노드 번호를 반환하면 된다. 중심은 모든 간선에 반드시 포함되어 있다는 성질을 이용하면 전체 목록을 볼 필요가 없다.

초보자는 처음에 이렇게 이해하면 된다.

`핵심 흐름: 첫 번째 간선의 두 노드 확인 → 두 번째 간선에도 있는 노드 선택 → 그것이 중심`

## 외워야 할 핵심 용어 5개

| 용어 | 초보자식 설명 |
|---|---|
| 스타 그래프 | 하나의 중심 노드가 나머지 모든 노드와 각각 1:1로 연결된 그래프 |
| 노드(node) | 그래프를 구성하는 점. 여기서는 번호로 표현된다 |
| 간선(edge) | 두 노드를 잇는 선. `[u, v]` 형태로 주어진다 |
| 차수(degree) | 하나의 노드에 연결된 간선의 수. 중심 노드는 차수가 n-1이다 |
| O(1) 복잡도 | 데이터 크기와 무관하게 연산 횟수가 상수인 이상적인 경우 |

## 예를 들어 설명하면

입력 `[[1,2],[2,3],[4,2]]` 에서:

```
간선 0: 노드 1 — 노드 2
간선 1: 노드 2 — 노드 3

간선 0의 노드는 {1, 2}
간선 1의 첫 번째 노드는 2

2가 두 간선 모두에 등장 → 중심은 2
```

코드로 표현하면 단 네 줄이다.

```java
public int findCenter(int[][] edges) {
    if (edges[0][0] == edges[1][0] || edges[0][0] == edges[1][1])
        return edges[0][0];
    return edges[0][1];
}
```

## 이 단계에서 중요한 판단 기준

문제의 제약 조건("스타 그래프가 보장된다")이 있을 때만 이 O(1) 풀이가 유효하다. 일반 그래프에서 최고 차수 노드를 찾으려면 모든 간선을 순회해야 한다.

## 한 줄 요약 — 이것만 기억하면 된다

**스타 그래프의 중심은 어느 두 간선에나 공통으로 등장하는 유일한 노드다.**

## 나중에 더 깊게 들어가면

- 일반 그래프에서 차수가 가장 높은 노드를 O(V+E)로 찾는 방법
- BFS/DFS로 연결 구조를 탐색하는 기본 패턴
- 트리와 그래프의 차이 — 사이클 유무
