> 아직 정렬되지 않은 원소를 하나씩 꺼내 이미 정렬된 부분의 올바른 위치에 끼워 넣는 방식으로, 작은 배열이나 거의 정렬된 데이터에 특히 효율적이다.

---

## 삽입 정렬을 왜 쓰는지 감 잡기

트럼프 카드를 한 장씩 집어 손에 쥘 때를 생각해보자. 새 카드를 받을 때마다 이미 손에 있는 카드들과 비교해 적절한 위치에 끼워 넣는다. 이것이 삽입 정렬의 전부다.

알고리즘 자체가 단순해서 구현이 쉽고, 거의 정렬된 데이터라면 비교 횟수가 크게 줄어 빠르다. 대신 배열이 클수록 비교와 이동이 많아져 O(n²) 시간이 걸리므로 대규모 데이터에는 적합하지 않다.

초보자는 처음에 이렇게 이해하면 된다.

`핵심 흐름: 다음 원소 선택 → 정렬된 구간에서 제자리 찾기 → 큰 원소들 오른쪽으로 밀기 → 삽입 → 반복`

## 외워야 할 핵심 용어 5개

| 용어 | 초보자식 설명 |
|---|---|
| 정렬 구간 | 이미 순서가 맞춰진 배열의 왼쪽 부분 |
| 미정렬 구간 | 아직 처리하지 않은 배열의 오른쪽 부분 |
| 삽입 위치 | 새 원소가 들어갈 자리. 정렬 구간을 오른쪽에서 왼쪽으로 훑으며 찾는다 |
| 이동(Shift) | 삽입 위치를 만들기 위해 원소들을 한 칸씩 오른쪽으로 밀어내는 동작 |
| 시간 복잡도 | 데이터 크기 n에 따른 연산 횟수. 삽입 정렬은 평균·최악 O(n²), 이미 정렬된 경우 최선 O(n) |

## 예를 들어 설명하면

`[4, 3, 2, 10, 1]`을 정렬한다.

```
초기:  [4] | [3, 2, 10, 1]
3 삽입: 3 < 4 → 4를 오른쪽으로 밀기 → [3, 4] | [2, 10, 1]
2 삽입: 2 < 4, 2 < 3 → 모두 밀기   → [2, 3, 4] | [10, 1]
10 삽입: 10 > 4 → 그대로            → [2, 3, 4, 10] | [1]
1 삽입: 1 < 모두 → 전부 밀기        → [1, 2, 3, 4, 10]
```

각 단계에서 정렬 구간은 항상 올바르게 정렬된 상태를 유지한다.

## 이 단계에서 중요한 판단 기준

데이터가 수백 개 이하이거나, 이미 거의 정렬된 상태라면 삽입 정렬이 퀵 정렬보다 실제로 더 빠를 수 있다.

## 한 줄 요약 — 이것만 기억하면 된다

**새 원소를 하나씩 꺼내 정렬된 구간의 올바른 자리에 끼워 넣는 단순하고 직관적인 정렬 방법이다.**

## 나중에 더 깊게 들어가면

- 이진 탐색을 활용해 삽입 위치를 더 빨리 찾는 이진 삽입 정렬
- 삽입 정렬을 내부적으로 활용하는 Timsort (Python, Java 기본 정렬)
- 셸 정렬: 삽입 정렬의 이동 횟수를 줄이기 위한 개선 버전
