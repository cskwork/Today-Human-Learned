## 로마 숫자 변환을 왜 쓰는지 감 잡기

로마 숫자는 고대 로마에서 쓰던 수 표기법으로, 오늘날에도 시계판, 영화 제작 연도, 책의 목차 등에 등장한다. 컴퓨터는 로마 숫자를 그 자체로 계산할 수 없어서 정수로 바꾸는 변환 과정이 필요하다. 이 문제는 문자열 파싱(parsing)과 규칙 기반 처리를 함께 연습하기 좋은 고전 예제다.

로마 숫자에는 하나의 특별한 규칙이 있다. 작은 숫자가 큰 숫자 앞에 오면 빼야 한다. 예를 들어 `IV`는 4이고 `IX`는 9다. 이 규칙을 가장 쉽게 처리하는 방법은 문자열을 거꾸로 읽는 것이다.

`핵심 흐름: 기호 → 값 조회 → 이전 값과 비교 → 더하거나 빼기 → 합산`

## 외워야 할 핵심 용어 5개

| 용어 | 초보자식 설명 |
|---|---|
| 딕셔너리(dictionary) | 기호와 값을 짝지어 저장하는 표. `'I': 1` 처럼 키와 값으로 이루어진다. |
| 역순 순회(reversed) | 문자열 끝에서부터 앞으로 하나씩 읽는 방법 |
| 뺄셈 규칙(subtraction rule) | 현재 값이 이미 처리한 값보다 작으면 더하지 않고 빼는 로마 숫자 규칙 |
| `prev_value` | 직전에 처리한 문자의 값. 현재 값과 비교하는 기준이 된다. |
| 누산기(accumulator) | `total` 변수처럼 결과를 하나씩 모아가는 변수 |

## 예를 들어 설명하면

`"MCMXCIV"` (1994)를 변환하는 과정을 역순으로 따라가 보자.

```python
def roman_to_int(s: str) -> int:
    values = {'I': 1, 'V': 5, 'X': 10, 'L': 50,
              'C': 100, 'D': 500, 'M': 1000}
    total = 0
    prev_value = 0

    for char in reversed(s):
        value = values[char]
        if value < prev_value:
            total -= value   # 예: I가 V 앞에 오면 빼기
        else:
            total += value
        prev_value = value

    return total
```

역순으로 읽으면 `V(5) I(1) C(100) X(10) M(1000) C(100) M(1000)` 순서가 된다. `I`를 처리할 때 `prev_value`는 5(V)이고 `I`는 1이므로 1을 뺀다. 이렇게 하면 뺄셈 규칙이 자연스럽게 해결된다.

## 이 단계에서 중요한 판단 기준

역순으로 읽어야 뺄셈 규칙을 별도 전처리 없이 단순한 대소 비교만으로 처리할 수 있다.
