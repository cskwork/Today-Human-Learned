---

## 비트 XOR을 왜 쓰는지 감 잡기

프로그램은 모든 데이터를 0과 1의 비트로 다룬다. XOR(Exclusive OR, 배타적 논리합)은 두 비트를 비교해 "둘 중 하나만 1일 때" 결과가 1이 되는 연산이다. 이 단순한 규칙이 여러 곳에서 유용하다. 배열에서 혼자만 존재하는 수 찾기, 비밀번호 없는 간단한 암호화, 데이터 전송 오류 감지 등이 모두 XOR에 의존한다.

XOR은 추가 메모리 없이 두 변수의 값을 교환하는 트릭으로도 쓰인다. 이런 활용이 가능한 이유는 XOR의 수학적 성질 때문이다.

`핵심 흐름: 두 비트 비교 → 같으면 0, 다르면 1 → 비트 단위로 전체 수에 적용`

## 외워야 할 핵심 용어 5개

| 용어 | 초보자식 설명 |
|---|---|
| 비트 연산(bitwise operation) | 수를 이진수(0과 1의 나열)로 보고 각 자릿수를 개별적으로 처리하는 연산 |
| XOR (^) | 두 비트가 다르면 1, 같으면 0. Python에서는 `^` 기호를 쓴다. |
| 자기 역원(self-inverse) | `A XOR A = 0`. 같은 수를 두 번 XOR하면 사라진다는 성질 |
| 항등원(identity) | `A XOR 0 = A`. 0과 XOR해도 원래 값이 변하지 않는다. |
| 교환법칙(commutative) | `A XOR B = B XOR A`. 순서를 바꿔도 결과가 같다. |

## 예를 들어 설명하면

4비트 수 `1101`(13)과 `1011`(11)을 XOR하면:

```
  1101
^ 1011
------
  0110  (6)
```

자릿수별로 비교한다. 첫째 자리: 1과 1 → 같으니 0. 둘째 자리: 1과 0 → 다르니 1. 셋째 자리: 0과 1 → 다르니 1. 넷째 자리: 1과 1 → 같으니 0. 결과는 `0110`(6)이다.

실용 예시: 배열 `[2, 3, 2, 4, 3]`에서 혼자만 있는 수를 찾으려면 모든 원소를 XOR한다. 짝이 있는 수는 `A XOR A = 0`으로 사라지고, 혼자 남은 수인 4만 남는다.

```python
nums = [2, 3, 2, 4, 3]
result = 0
for n in nums:
    result ^= n   # 2^3^2^4^3 = 4
```

## 이 단계에서 중요한 판단 기준

"짝을 이루는 원소들을 제거하고 나머지를 찾아야 한다"는 조건이 보이면, XOR이 추가 메모리 없이 O(N) 해결책을 제공한다.

## 한 줄 요약 — 이것만 기억하면 된다

**XOR은 같으면 0, 다르면 1이고, 자기 자신과 XOR하면 0이 되는 성질 덕분에 짝 없는 원소 찾기와 암호화에 자주 쓰인다.**

## 나중에 더 깊게 들어가면

- XOR을 이용한 두 변수 스왑(`a ^= b; b ^= a; a ^= b`)의 원리
- XOR 기반 체크섬과 오류 감지 코드(CRC)
- 비트 마스킹: AND, OR, XOR, NOT을 조합해 특정 비트만 읽거나 쓰는 기법
