> **TL;DR**
> JavaScript는 8가지 자료형을 가지며, 변수 선언은 `let`/`const`를 쓰고, 형변환은 명시적(`Number()`, `String()`, `Boolean()`)과 암묵적 변환 두 가지가 있다.

---

## 이 개념들을 왜 알아야 하는지 감 잡기

프로그램은 결국 데이터를 받아 처리하고 출력하는 일이다. 어떤 종류의 데이터를 어떤 그릇에 담을 수 있는지, 그리고 그릇을 바꿔야 할 때 어떤 일이 벌어지는지를 모르면 예상치 못한 버그가 생긴다. JavaScript는 타입 선언 없이 값을 담을 수 있어서 편리하지만, 그만큼 형변환 규칙을 명확히 알아야 한다.

초보자는 처음에 이렇게 이해하면 된다.

`핵심 흐름: 변수 선언 → 자료형 확인(typeof) → 필요시 형변환(Number/String/Boolean)`

## 외워야 할 핵심 용어 5개

| 용어 | 초보자식 설명 |
|---|---|
| let | 값을 나중에 바꿀 수 있는 변수 선언 키워드. 모던 JavaScript의 기본 선택이다. |
| const | 한번 할당하면 재할당이 불가능한 변수 선언 키워드. 바뀌지 않는 값에는 항상 const를 쓴다. |
| typeof | 변수나 값의 자료형을 문자열로 반환하는 연산자. 디버깅할 때 자주 쓴다. |
| null vs undefined | null은 개발자가 "값이 없음"을 명시적으로 설정한 것, undefined는 아직 값이 할당되지 않은 상태다. |
| 암묵적 형변환 | 연산자나 조건식에서 JavaScript가 자동으로 타입을 바꾸는 동작. 의도치 않은 결과를 낳을 수 있다. |

## 예를 들어 설명하면

형변환 규칙 중 초보자가 가장 많이 틀리는 부분은 숫자형 변환과 불린형 변환이다.

```js
// 숫자형으로 변환
Number(null)       // 0
Number(undefined)  // NaN  <- null과 다름, 주의
Number("")         // 0
Number("3.14")     // 3.14
Number("abc")      // NaN

// 불린형으로 변환 — falsy 값 6개만 외우면 된다
Boolean(0)         // false
Boolean("")        // false
Boolean(null)      // false
Boolean(undefined) // false
Boolean(NaN)       // false
Boolean("0")       // true  <- "0"은 빈 문자열이 아니므로 true
Boolean(" ")       // true  <- 공백도 true
```

`var`는 함수 스코프를 가지고 호이스팅 동작이 직관적이지 않아 현재는 사용을 피한다. 새 코드는 `let`과 `const`만 쓴다.

## 이 단계에서 중요한 판단 기준

형변환이 자동으로 일어나는 상황(`==` 연산자, `if` 조건문 등)에서는 예측이 어렵기 때문에, 비교는 항상 `===`(엄격 동등)을 쓰고 명시적으로 변환한 뒤 사용하는 것이 안전하다.

## 한 줄 요약 — 이것만 기억하면 된다

**변수는 `let`/`const`로 선언하고, 타입이 섞이는 연산에서는 `Number()` · `String()` · `Boolean()`으로 명시적으로 변환해 의도를 드러낸다.**

## 나중에 더 깊게 들어가면

- `==`와 `===`의 차이 및 타입 강제 변환 테이블
- `BigInt` 자료형이 필요한 상황 (2^53 이상의 정수 처리)
- 심볼(Symbol)형의 실제 사용 사례 (객체 속성 충돌 방지)
