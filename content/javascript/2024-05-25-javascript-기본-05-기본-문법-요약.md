> **TL;DR**
> 자바스크립트의 세미콜론, 변수, 자료형, 연산자, 반복문, 함수 선언 방식은 패턴이 정해져 있다. 규칙을 알면 코드를 읽는 속도가 빨라진다.

---

## 이 주제를 왜 알아야 하는지 감 잡기

자바스크립트는 세미콜론을 생략해도 실행되지만, 생략 규칙이 예상과 다르게 작동하는 경우가 있다. 변수 선언 방식이 세 가지(`var`, `let`, `const`)고 자료형이 여덟 가지다. 이것들을 혼동하면 예측하기 어려운 버그가 생긴다. 기본 문법을 한 번 훑어두면 낯선 코드를 읽을 때 멈추는 횟수가 줄어든다.

초보자는 처음에 이렇게 이해하면 된다.

`핵심 흐름: 코드 작성 → JS 엔진이 파싱 → 자료형 결정 → 연산/분기/반복 → 함수 호출`

## 외워야 할 핵심 용어 5개

| 용어 | 초보자식 설명 |
|---|---|
| 세미콜론 자동 삽입 (ASI) | 줄 바꿈을 세미콜론으로 간주하는 규칙인데, 배열 `[`로 시작하는 줄에서는 작동하지 않아 버그가 난다 |
| `use strict` | "옛날 방식은 쓰지 마라"고 엔진에 선언하는 지시어. 파일 맨 위에 한 줄 추가한다 |
| `let` / `const` | `let`은 값을 나중에 바꿀 수 있는 변수, `const`는 한 번 할당하면 바꿀 수 없는 상수 |
| 일치 연산자 `===` | 값과 자료형을 동시에 비교한다. `==`는 자료형을 자동 변환해서 비교하므로 예상 밖 결과가 나온다 |
| `typeof` | 값의 자료형을 문자열로 돌려준다. 단, `typeof null`은 버그로 인해 `"object"`를 반환한다 |

## 예를 들어 설명하면

세미콜론을 생략했을 때 문제가 생기는 전형적인 사례다.

```js
alert("이 메시지 출력 후 에러 발생")
[1, 2].forEach(alert)
```

엔진은 두 번째 줄 `[`를 첫 번째 줄과 연결해서 `alert(...)[1, 2]` 형태로 파싱한다. 세미콜론을 명시하면 이런 문제가 없다. 코딩 컨벤션 대부분이 세미콜론을 권장하는 이유다.

함수는 세 가지 형태로 선언할 수 있다.

```js
// 선언문 — 호이스팅됨(파일 어디서든 호출 가능)
function sum(a, b) { return a + b; }

// 표현식 — 변수에 함수를 할당
const sum = function(a, b) { return a + b; };

// 화살표 함수 — 가장 짧은 형태
const sum = (a, b) => a + b;
```

## 이 단계에서 중요한 판단 기준

변수는 기본적으로 `const`를 쓰고, 값이 바뀌어야 할 때만 `let`으로 바꾸며, `var`는 신규 코드에서 쓰지 않는다.

## 한 줄 요약 — 이것만 기억하면 된다

**`const` 우선, 세미콜론 명시, `===` 사용, `use strict` 선언 — 이 네 가지 습관이 초보자의 버그를 절반으로 줄인다.**

## 나중에 더 깊게 들어가면

- 호이스팅(hoisting): 함수 선언문이 실행 전에 끌어올려지는 동작 원리
- 클로저(closure): 함수가 외부 변수를 기억하는 방식
- 프로토타입(prototype): 자바스크립트 객체 상속 구조
