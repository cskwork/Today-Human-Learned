## 단축 문법을 왜 쓰는지 감 잡기

`for` 루프로 배열을 순회하며 조건에 맞는 값을 새 배열에 밀어 넣는 코드는 5-6줄이다. `filter` 한 줄로 같은 일을 한다. 코드 길이 자체보다 중요한 것은 **의도의 명확함**이다. "무엇을 원하는가"를 선언하는 방식이 "어떻게 하는가"를 지시하는 방식보다 읽기 쉬울 때가 많다.

ES6+ 단축 문법이 그 도구다. 단, 너무 많이 중첩하면 오히려 이해하기 어렵다. 절제가 핵심이다.

`핵심 흐름: 명령형(for + push) → 선언형(map/filter/reduce) → 의도 명확한 코드`

## 외워야 할 핵심 용어 5개

| 용어 | 초보자식 설명 |
|---|---|
| 화살표 함수 | `function` 키워드 없이 `(a, b) => a + b` 형태로 쓰는 짧은 함수 표기법. |
| 구조 분해 할당 | 배열이나 객체에서 값을 꺼내 변수에 한 번에 담는 문법. `const [a, b] = [1, 2]` |
| 전개 구문 | `...`으로 배열이나 객체를 펼치거나 합치는 문법. |
| 삼항 연산자 | `조건 ? 참값 : 거짓값` — 간단한 if-else를 한 줄로 표현한다. |
| 단락 평가 | `&&`나 `||`가 왼쪽 값에 따라 오른쪽을 평가하지 않고 멈추는 동작. |

## 예를 들어 설명하면

10가지 패턴을 Before/After로 정리했다.

```js
// 1. 두 변수 교환 — 임시 변수 불필요
[a, b] = [b, a];

// 2. 배열 중복 제거
const unique = [...new Set([1, 2, 2, 3])]; // [1, 2, 3]

// 3. 조건부 객체 속성 추가
const obj = { ...base, ...(flag && { email: 'a@b.com' }) };

// 4. 배열 섞기 (간단한 용도에만 적합)
arr.sort(() => Math.random() - 0.5);

// 5. 0~N-1 숫자 배열 생성
const range = Array.from({ length: 5 }, (_, i) => i); // [0,1,2,3,4]

// 6. 조건 일괄 확인
ages.every(a => a >= 18); // 전부 성인?
ages.some(a => a < 18);   // 미성년자 있나?

// 7. 중첩 배열 평탄화
[1, [2, [3]]].flat(Infinity); // [1, 2, 3]

// 8. 경로에서 파일명 추출
'/src/index.js'.split('/').pop(); // 'index.js'

// 9. 삼항 연산자
const status = isLoggedIn ? 'Logged In' : 'Logged Out';

// 10. 단순 계산 화살표 함수
const multiply = (a, b) => a * b;
```

## 이 단계에서 중요한 판단 기준

삼항 연산자를 중첩하거나 메서드를 4개 이상 체이닝하면 동료가 읽기 어렵다. 한 줄로 줄였을 때 설명이 필요하다면, 원래 여러 줄이 낫다.
