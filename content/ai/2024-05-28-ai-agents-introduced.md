> AI 에이전트는 목표가 주어지면 환경을 인식하고 스스로 추론해 행동까지 수행하는 자율 소프트웨어다.

---

## AI 에이전트를 왜 쓰는지 감 잡기

일반적인 소프트웨어는 입력이 들어오면 미리 정해진 규칙대로 출력을 낸다. AI 에이전트는 다르다. 목표만 주면 상황을 파악하고, 어떤 행동이 필요한지 스스로 판단하며, 결과를 보면서 다음 행동을 바꾼다. 고객 지원 챗봇, 코드 자동 수정 도구, 자율 데이터 수집 파이프라인 같은 곳에서 쓴다. 사람의 개입 없이 반복 작업을 처리하거나, 예측 불가능한 입력에 동적으로 대응해야 할 때 특히 유용하다.

초보자는 처음에 이렇게 이해하면 된다.

`핵심 흐름: 환경 인식(Perception) → 추론(Reasoning) → 행동(Action) → 결과 반영 → 반복`

## 외워야 할 핵심 용어 5개

| 용어 | 초보자식 설명 |
|---|---|
| 자율성(Autonomy) | 사람의 지시 없이도 스스로 결정하고 실행할 수 있는 능력. |
| 인식(Perception) | 텍스트, 이미지, 센서 데이터 등 외부 환경으로부터 정보를 읽어들이는 과정. |
| 추론(Reasoning) | 수집한 정보를 바탕으로 어떤 행동이 목표에 가장 가까운지 판단하는 과정. |
| 행동(Action) | 추론 결과를 실제로 실행하는 것. API 호출, 파일 쓰기, 메시지 전송 등이 해당된다. |
| 도구 사용(Tool use) | 에이전트가 검색, 계산기, 코드 실행기 등 외부 도구를 직접 호출해 능력을 확장하는 방식. |

## 예를 들어 설명하면

웹사이트 고객 지원 챗봇을 생각해보자.

- **인식**: 사용자가 "주문 상태를 확인하고 싶어요"라고 입력한다. 에이전트는 이 텍스트를 읽는다.
- **추론**: NLP 모델이 의도를 파악한다. "주문 조회" 기능이 필요하다고 판단한다.
- **행동**: 주문 관리 API를 호출해 해당 사용자의 주문 상태를 조회하고 결과를 반환한다.
- **반복**: 사용자가 "배송 주소를 바꿀 수 있나요?"라고 추가 질문하면 같은 루프를 다시 시작한다.

24시간 내내 사람 없이 이 루프를 반복하는 것이 에이전트의 핵심 가치다.

## 이 단계에서 중요한 판단 기준

에이전트를 도입할 때 가장 먼저 따져야 할 것은 "실패 시 되돌릴 수 있는 작업인가"다. 파일 삭제나 결제처럼 되돌릴 수 없는 행동은 사람의 확인 단계를 반드시 포함해야 한다.

## 한 줄 요약 — 이것만 기억하면 된다

**AI 에이전트는 인식-추론-행동 루프를 자율적으로 반복해 목표를 달성하는 소프트웨어다.**

## 나중에 더 깊게 들어가면

- ReAct 패턴: 추론(Reasoning)과 행동(Action)을 교대로 반복하는 에이전트 설계 방식
- 멀티 에이전트 시스템: 여러 에이전트가 역할을 나눠 협력하는 구조
- 에이전트의 메모리 관리: 단기(컨텍스트 창) vs 장기(벡터 DB) 기억 저장 방법
