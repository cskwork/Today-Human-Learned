## ChatGPT를 왜 쓰는지 감 잡기

인터넷 검색은 페이지를 찾아준다. ChatGPT는 페이지 대신 답을 만들어준다.
GPT 모델은 방대한 텍스트를 학습해 언어 패턴을 익혔다. 그 결과로 질문에 맞는 텍스트를 생성할 수 있다.
의료 정보, 법률, 프로그래밍처럼 도메인이 특화된 GPTs도 있어 더 좁고 깊은 용도로 활용할 수 있다.

주의할 점이 있다. ChatGPT는 인터넷에 실시간으로 연결되지 않는다.
학습 데이터의 컷오프 이후 정보는 모른다. 사실 확인이 필요한 정보는 원본 소스를 따로 찾아야 한다.

`핵심 흐름: 프롬프트 입력 -> 모델 추론 -> 텍스트 생성 -> 사용자 검토`

## 외워야 할 핵심 용어 5개

| 용어 | 초보자식 설명 |
|---|---|
| GPT | 대규모 텍스트로 사전 학습된 언어 생성 모델. ChatGPT의 엔진 |
| 프롬프트 | 모델에 전달하는 입력. 질문, 지시, 배경 설명을 포함할 수 있다 |
| GPTs | 특정 목적에 맞게 커스텀된 ChatGPT. 의료, 법률, 코딩 등 전문 버전이 있다 |
| 할루시네이션 | 모델이 사실이 아닌 내용을 자신 있게 말하는 현상. 출처 확인이 필수인 이유 |
| 컨텍스트 창 | 모델이 한 대화에서 기억하는 최대 텍스트 길이. 초과하면 앞 내용을 잊는다 |

## 예를 들어 설명하면

ChatGPT에 파이썬 코드 작성을 요청하는 상황이다.

```
사용자: "파일을 읽고 내용을 출력하는 파이썬 스크립트를 작성해줘."

ChatGPT:
with open('example.txt', 'r') as file:
    contents = file.read()
    print(contents)

# with open은 블록이 끝나면 자동으로 파일을 닫는다.
# 예외가 발생해도 파일이 안전하게 닫힌다.
```

요청이 구체적일수록 결과가 정확하다.
"파이썬 코드 짜줘" 대신 "Python 3.11, UTF-8 인코딩, 줄 단위 출력"처럼 조건을 붙이면 쓸 수 있는 코드가 나온다.

## 이 단계에서 중요한 판단 기준

ChatGPT 출력을 그대로 믿지 않는다. 중요한 사실, 법률, 의학 정보는 반드시 공식 출처에서 검증한 후 사용한다.

## 한 줄 요약 — 이것만 기억하면 된다

**ChatGPT는 자연어 프롬프트로 텍스트 생성, 요약, 코드 작성을 요청할 수 있는 도구이며, 결과물은 항상 검토가 필요하다.**

## 나중에 더 깊게 들어가면

- 프롬프트 엔지니어링: 역할 부여(system prompt), Few-shot 예시, 단계별 추론 유도
- API 활용: OpenAI SDK로 ChatGPT를 자신의 서비스에 연동하는 방법
