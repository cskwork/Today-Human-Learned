## Claude Opus 4.6을 왜 쓰는지 감 잡기

AI 모델 성능 경쟁에서 컨텍스트 길이는 실무 한계선이다. 긴 코드베이스를 분석하거나 수백 페이지 문서를 한 번에 처리하려면 모델이 얼마나 많은 내용을 한 번에 기억할 수 있는지가 관건이다. 기존 Opus급 모델은 200K 토큰이 상한이었다. Opus 4.6은 이 한계를 100만 토큰으로 늘리면서, 동시에 에이전트 코딩과 추론 벤치마크에서 경쟁 모델을 앞질렀다.

Anthropic은 자체 엔지니어들이 매일 Claude Code로 코딩하면서 새 모델을 먼저 검증한다고 밝혔다. 실험실 벤치마크가 아닌 실전 사용 환경에서 테스트된 모델이라는 점이 이전과 다르다.

초보자는 처음에 이렇게 이해하면 된다.

`핵심 흐름: 긴 입력 처리 → 에이전트 코딩 실행 → 100만 토큰 범위 내 정보 유지`

## 외워야 할 핵심 용어 5개

| 용어 | 초보자식 설명 |
|---|---|
| 컨텍스트 창 | AI 모델이 한 번에 읽을 수 있는 텍스트의 최대 길이. 100만 토큰은 대략 소설 수십 권 분량 |
| Adaptive Thinking | 간단한 질문엔 빠르게, 복잡한 문제엔 깊이 사고하도록 모델이 스스로 조절하는 방식 |
| Context Compaction | 대화가 길어져 컨텍스트 창이 가득 찰 때 이전 내용을 자동 요약해서 공간을 확보하는 기능 |
| Effort 레벨 | API에서 모델의 추론 깊이를 low/medium/high/max로 조절하는 파라미터. 간단한 작업에 high를 쓰면 비용이 낭비된다 |
| Agent Teams | 여러 Claude Code 인스턴스가 팀으로 협업해 병렬로 작업을 처리하는 기능 |

## 예를 들어 설명하면

주요 벤치마크 결과를 보면 차이가 뚜렷하다.

| 벤치마크 | 측정 영역 | Opus 4.6 | Opus 4.5 |
|---|---|---|---|
| Terminal-Bench 2.0 | 에이전트 코딩 | 65.4% | 59.8% |
| BrowseComp | 에이전트 검색 | 84.0% | 67.8% |
| ARC AGI 2 | 새로운 문제 해결 | 68.8% | 37.6% |
| GDPval-AA Elo | 실무 지식 작업 | 1,606 | 1,416 |

ARC AGI 2는 학습 데이터에 없는 완전히 새로운 패턴을 추론하는 테스트다. 전작 대비 거의 두 배 가까운 도약(37.6% -> 68.8%)은 단순 암기가 아닌 추론 능력의 실질적 향상을 보여준다.

100만 토큰 컨텍스트가 실제로 유용한지는 MRCR v2로 검증됐다. 100만 토큰 분량의 텍스트 속에 숨겨진 정보 8개를 찾는 난이도에서 Opus 4.6은 76%를 기록했다. 같은 조건에서 Sonnet 4.5는 18.5%에 그쳤다.

## 이 단계에서 중요한 판단 기준

Effort 레벨 기본값은 high다. 간단한 작업에서는 medium으로 낮춰야 불필요한 비용과 지연을 줄일 수 있다.

## 한 줄 요약 — 이것만 기억하면 된다

**Opus 4.6은 100만 토큰 컨텍스트와 에이전트 코딩 성능 향상을 전작과 동일한 가격($5/$25 입력/출력, 백만 토큰당)에 제공한다. 단, 200K 토큰 초과 시 프리미엄 가격이 적용된다는 점을 확인하라.**
