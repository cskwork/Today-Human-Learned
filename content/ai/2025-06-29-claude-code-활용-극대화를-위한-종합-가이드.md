> Claude Code는 터미널에서 자연어로 코드를 작성·수정·디버깅하는 에이전틱 도구다. 사고 모드, CLAUDE.md, 병렬 실행을 조합하면 생산성이 크게 올라간다.

---

## Claude Code를 왜 쓰는지 감 잡기

일반 코드 자동완성 도구는 현재 파일 한 줄만 본다. Claude Code는 프로젝트 전체를 읽고, 터미널 명령을 실행하며, 여러 파일을 동시에 수정한다. 자연어로 "이 버그 고쳐줘"라고 하면 원인을 분석하고 수정까지 처리한다.

사용자는 요구사항을 설명하는 역할만 한다. Claude Code가 코드를 탐색하고, 테스트를 돌리고, 결과를 검증한다.

초보자는 처음에 이렇게 이해하면 된다.

`핵심 흐름: 자연어 지시 → 코드베이스 탐색 → 수정 실행 → 검증`

## 외워야 할 핵심 용어 5개

| 용어 | 초보자식 설명 |
|---|---|
| 에이전틱 코딩 | AI가 계획을 세우고, 도구를 쓰고, 결과를 확인하는 여러 단계를 스스로 처리하는 방식 |
| CLAUDE.md | 프로젝트 규칙(코딩 스타일, 빌드 명령 등)을 Claude에게 알려주는 설명서 파일 |
| 사고 모드 | "think" 또는 "ultrathink" 키워드로 Claude가 더 깊이 추론하도록 유도하는 방식 |
| 컨텍스트 창 | Claude가 한 번에 처리할 수 있는 대화·코드의 양; 넘치면 오래된 내용이 잘린다 |
| Pre-commit hook | 코드를 저장소에 올리기 직전에 자동으로 테스트·린팅을 돌려주는 장치 |

## 예를 들어 설명하면

반복 작업을 슬래시 명령어로 자동화하는 예시다.

```markdown
# .claude/commands/fix-issue.md
GitHub 이슈 분석 및 수정: $ARGUMENTS
1. `gh issue view`로 이슈 상세 정보 확인
2. 문제 원인 파악
3. 관련 파일 검색
4. 수정 구현 및 테스트
```

이 파일을 저장하면 `/fix-issue 123` 한 줄로 전체 흐름이 실행된다.

## 이 단계에서 중요한 판단 기준

Claude Code를 마법 상자가 아닌 지능적인 파트너로 대할 때, 즉 구체적인 요구사항과 예시를 주었을 때 성공률이 크게 높아진다.

## 한 줄 요약 — 이것만 기억하면 된다

**CLAUDE.md로 프로젝트 맥락을 주고, 사고 모드로 복잡한 문제를 맡기면 Claude Code는 단순 보조 도구를 넘어 실질적인 개발 파트너가 된다.**
