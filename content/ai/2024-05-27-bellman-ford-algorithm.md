> **TL;DR**
> 벨만-포드는 간선 가중치가 음수여도 작동하는 최단 경로 알고리즘이며, 음수 사이클까지 검출할 수 있다.

---

## 벨만-포드를 왜 쓰는지 감 잡기

지도에서 최단 경로를 찾을 때 가장 먼저 떠오르는 건 다익스트라(Dijkstra) 알고리즘이다. 그런데 다익스트라는 간선 가중치가 모두 양수일 때만 동작한다. 현실에서는 할인 쿠폰, 캐시백, 부채처럼 음수 값이 비용에 포함되는 경우가 있다. 이럴 때 벨만-포드를 쓴다. 모든 간선을 반복적으로 완화(relax)하는 방식이라 속도는 다익스트라보다 느리지만, 음수 가중치와 음수 사이클 탐지 모두 지원한다.

초보자는 처음에 이렇게 이해하면 된다.

`핵심 흐름: 거리 초기화 → 간선 완화 반복 (V-1회) → 음수 사이클 검사`

## 외워야 할 핵심 용어 5개

| 용어 | 초보자식 설명 |
|---|---|
| 그래프(Graph) | 노드(지점)와 간선(연결선)으로 이루어진 구조. 도시와 도로를 생각하면 된다. |
| 가중치(Weight) | 간선에 붙은 비용이나 거리. 양수일 수도, 음수일 수도 있다. |
| 완화(Relaxation) | "지금까지 알고 있던 최단 거리보다 더 짧은 경로를 발견하면 값을 갱신한다"는 동작. |
| 음수 사이클(Negative-weight cycle) | 순환 경로를 한 바퀴 돌면 총 비용이 줄어드는 사이클. 무한히 비용을 낮출 수 있어 최단 경로가 정의되지 않는다. |
| V-1 반복 | 노드가 V개일 때 최단 경로는 최대 V-1개의 간선을 사용하므로, 완화를 V-1번 반복하면 모든 경로가 확정된다. |

## 예를 들어 설명하면

노드 A, B, C, D, E가 있고 다음 간선이 존재한다고 하자.

```
A-B(4), A-C(2), C-B(1), B-D(2), D-E(1), E-D(-3)
```

출발지 A의 거리를 0, 나머지를 무한대(∞)로 초기화한다.

1회 완화 후 결과 예시:

| 노드 | 거리 |
|---|---|
| A | 0 |
| B | 3 (A→C→B = 2+1) |
| C | 2 |
| D | 5 (A→C→B→D = 3+2) |
| E | 6 (A→C→B→D→E = 5+1) |

V-1 = 4회 반복 후에도 거리가 줄어드는 간선이 있으면 음수 사이클이 존재한다는 신호다. 위 예에서 E-D(-3) 때문에 D의 거리가 계속 줄어들 수 있으니, 해당 그래프에는 음수 사이클이 있다.

## 이 단계에서 중요한 판단 기준

간선에 음수 가중치가 있거나 음수 사이클 탐지가 필요하면 벨만-포드를, 그렇지 않으면 더 빠른 다익스트라를 선택한다.

## 한 줄 요약 — 이것만 기억하면 된다

**벨만-포드는 음수 가중치 간선이 있는 그래프에서 최단 경로를 찾고 음수 사이클을 검출하는 알고리즘이다.**

## 나중에 더 깊게 들어가면

- 다익스트라와 시간 복잡도 비교 (O(VE) vs O((V+E) log V))
- 음수 사이클이 존재할 때 실무에서 어떻게 처리하는가
- 벨만-포드를 개선한 SPFA(Shortest Path Faster Algorithm)
