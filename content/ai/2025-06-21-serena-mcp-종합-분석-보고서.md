> **TL;DR**
> Serena MCP는 IDE의 심볼 분석 기능을 AI 에이전트에게 그대로 넘겨주는 무료 오픈소스 도구다. 강력하지만 보안 설정 없이 프로덕션에 쓰면 위험하다.

---

## Serena MCP를 왜 쓰는지 감 잡기

일반적인 AI 코딩 도구는 코드를 텍스트로 읽는다. 파일을 통째로 읽어서 패턴을 찾는 방식이다. Serena MCP는 다르다. IDE가 "정의로 이동", "참조 찾기"를 처리하는 방식 — Language Server Protocol(LSP) — 을 그대로 AI 에이전트에게 연결한다. 덕분에 에이전트가 심볼 수준에서 코드를 이해하고 편집한다.

2025년 4월 출시. 완전 무료이며 Claude Desktop, VSCode, Cursor 등 MCP를 지원하는 모든 클라이언트에서 쓸 수 있다.

`핵심 흐름: 코드베이스 → LSP 분석 → 심볼 그래프 → AI 에이전트 조작`

## 외워야 할 핵심 용어 5개

| 용어 | 초보자식 설명 |
|---|---|
| LSP (Language Server Protocol) | IDE가 "이 함수가 어디서 쓰이나?" 같은 질문에 답하기 위해 쓰는 표준 통신 규격 |
| MCP (Model Context Protocol) | AI 모델이 외부 도구를 호출할 때 쓰는 표준 인터페이스 |
| 심볼 레벨 분석 | 변수명, 함수명, 클래스 같은 코드의 의미 단위를 이해하는 것 (단순 텍스트 검색과 다름) |
| 프로젝트 메모리 | `.serena/memories/` 폴더에 저장되는 세션 간 컨텍스트. 에이전트가 이전 작업을 기억한다. |
| 셸 실행 도구 | Serena가 빌드, 테스트, 배포 명령을 직접 실행할 수 있는 기능 (보안 위험의 핵심) |

## 예를 들어 설명하면

대규모 Python 프로젝트에서 `UserService` 클래스의 `get_by_id` 메서드를 리팩토링한다고 하자.

텍스트 기반 도구는 파일 전체를 읽고 문자열 검색으로 참조를 찾는다. Serena는 LSP를 통해 심볼 그래프에서 `get_by_id`의 모든 호출 지점을 정확히 찾고, 타입 정보까지 확인하면서 편집한다. 35개 이상의 전문 도구가 분석, 편집, 파일 조작, 셸 실행을 포괄한다.

## 이 단계에서 중요한 판단 기준

보안 위험이 핵심 판단 기준이다. 셸 명령 실행, 인증 없는 웹 대시보드, 프롬프트 인젝션 취약점이 존재하므로 프로덕션 환경에서는 반드시 `read_only: true` 설정과 Docker 격리를 먼저 적용한다.

## 한 줄 요약 — 이것만 기억하면 된다

**대규모 코드베이스 분석에 LSP 기반 심볼 이해가 필요하다면 Serena MCP가 유효한 선택이지만, 보안 격리 없이는 쓰지 않는다.**
