> **TL;DR**
> Agentic Vision은 코드 실행을 통해 이미지를 확대하고 조작하며 반복적으로 분석하는 새로운 AI 비전 방식으로, 기존 정적 처리 대비 5~10% 품질 향상을 가져온다.

---

## Agentic Vision을 왜 쓰는지 감 잡기

AI에게 미세한 글씨가 적힌 이미지를 보여주면 어떤 일이 벌어지는가. 대부분의 AI는 한 번 흘끗 보고 답변한다. 마이크로칩의 일련번호, 건축 도면의 세부 치수, 멀리 있는 도로 표지판처럼 세밀한 정보가 필요할 때 모델은 추측에 의존할 수밖에 없다.

Google이 2026년 1월 27일 발표한 Gemini 3 Flash의 Agentic Vision은 이 문제를 다른 방식으로 해결한다. 이미지를 정적으로 한 번 처리하는 대신, 필요한 부분을 확대하고 잘라내고 분석하는 과정을 코드로 실행하며 반복한다.

의사가 엑스레이를 한 번 훑어보는 것과 돋보기를 들고 특정 부위를 집중 검사하는 것의 차이다.

초보자는 처음에 이렇게 이해하면 된다.

`핵심 흐름: 이미지 수신 → Think(계획) → Act(코드 실행) → Observe(결과 확인) → 필요 시 반복`

## 외워야 할 핵심 용어 5개

| 용어 | 초보자식 설명 |
|---|---|
| Agentic Vision | AI가 이미지를 수동으로 보는 것이 아니라 코드 실행을 통해 능동적으로 조사하는 방식 |
| Think-Act-Observe 루프 | 계획 세우기 → 코드 실행 → 결과 검토를 반복하는 세 단계 사이클 |
| 코드 실행 (Code Execution) | AI가 직접 Python 코드를 작성하고 실행해서 이미지를 조작하는 기능 |
| 결정론적 실행 | 확률적 추측이 아닌 코드가 실제로 실행된 검증 가능한 결과를 얻는 것 |
| 바운딩 박스 | 이미지 내 특정 객체 주변에 그리는 사각형 테두리. 위치와 개수를 정확히 파악할 때 사용 |

## 예를 들어 설명하면

손가락 개수를 세는 작업을 예로 들면: 기존 AI는 이미지를 보고 "5개"라고 추측한다. Agentic Vision은 각 손가락에 바운딩 박스와 숫자 레이블을 코드로 직접 그려넣은 뒤 개수를 확인한다. 이것이 "시각적 메모장"이다.

건축 도면 검증 플랫폼에서는 모델이 지붕 가장자리나 건물 섹션을 반복적으로 잘라내고 분석하여 복잡한 건축 법규 준수 여부를 확인한다. 이 방식으로 정확도가 5% 향상됐다.

사용 환경별 접근 방법:

| 사용 환경 | 접근 방법 |
|---|---|
| 개발자 (API) | Google AI Studio 또는 Vertex AI에서 Code Execution 활성화 |
| 일반 사용자 (앱) | Gemini 앱 모델 드롭다운에서 Thinking 선택 |
| 기능 테스트 | Google AI Studio 내 데모 앱 직접 체험 |

## 이 단계에서 중요한 판단 기준

정밀도가 필요한 작업(세밀한 텍스트 읽기, 정확한 계산, 고해상도 도면 검증)에서만 Code Execution을 켠다. 단순한 이미지 설명이나 분류 작업에서는 기존 방식이 더 빠르고 효율적이다.

## 한 줄 요약 — 이것만 기억하면 된다

**Agentic Vision은 AI가 이미지를 추측하는 것에서 코드로 검증하는 것으로 바꾼다.**

## 나중에 더 깊게 들어가면

- Think-Act-Observe 루프를 커스텀 파이프라인에 통합하는 방법
- Vertex AI에서 Code Execution을 프로덕션 환경에 안정적으로 배포하기
- 다른 멀티모달 모델(GPT-4o, Claude 3.5)과 시각 추론 정확도 비교
