> **TL;DR**
> AI 에이전트 팀 실험은 소프트웨어 개발의 단위를 "작업"에서 "프로젝트"로 바꾸는 신호이며, 개발자의 핵심 역량이 코드 작성에서 시스템 설계와 검증 엔지니어링으로 이동하고 있음을 보여준다.

---

## 이 주제를 왜 쓰는지 감 잡기

컴파일러는 컴퓨터 과학에서 가장 복잡한 소프트웨어 중 하나다. GCC는 수백 명의 개발자가 40년 넘게 다듬어온 결과물이다. 2026년 2월, Anthropic의 Safeguards팀 연구원 Nicholas Carlini는 Claude Opus 4.6 모델 16개로 2주 만에 10만 줄짜리 C 컴파일러를 만들었다. Linux 6.9 커널을 실제로 빌드하고 부팅까지 성공한 컴파일러다.

AI가 코드를 잘 짠다는 이야기가 아니다. 소프트웨어를 만드는 방식 자체가 달라지고 있다는 신호다.

`핵심 흐름: 에이전트 16개 → Git 공유 저장소 → 무한 루프 작업 → 역할 전문화 → 10만 줄 Rust 컴파일러`

## 외워야 할 핵심 용어 5개

| 용어 | 초보자식 설명 |
|---|---|
| 에이전트 팀 | 여러 AI 인스턴스가 하나의 코드베이스에서 병렬로 작업하며 사람 없이 프로젝트를 완성하는 방식 |
| 락 파일 | 에이전트가 특정 작업을 "내가 하고 있음"으로 표시하는 텍스트 파일. Git 충돌이 자연스러운 중재자 역할을 한다 |
| 오라클 비교 | GCC를 정답 기준으로 삼아 CCC의 버그를 좁혀가는 이분 탐색 전략 |
| 컨텍스트 오염 | 테스트 로그가 너무 많으면 AI의 컨텍스트 윈도우를 잡아먹어 판단이 흐려지는 현상 |
| CCC (Claude's C Compiler) | 이 실험의 결과물. Rust로 작성된 10만 줄 규모의 C 컴파일러 |

## 예를 들어 설명하면

프로젝트 규모를 수치로 먼저 보면 이렇다.

| 항목 | 수치 |
|---|---|
| 투입 에이전트 | 16개 (Claude Opus 4.6) |
| 총 Claude Code 세션 | 약 2,000회 |
| 소요 기간 | 약 2주 |
| 총 비용 | 약 2만 달러 |
| 코드 규모 | 약 10만 줄 (Rust) |

각 에이전트는 무한 루프 하네스 안에서 작동한다.

```bash
#!/bin/bash
while true; do
    COMMIT=$(git rev-parse --short=6 HEAD)
    LOGFILE="agent_logs/agent_${COMMIT}.log"
    claude -p "$(cat AGENT_PROMPT.md)" \
           --model claude-opus-X-Y &> "$LOGFILE"
done
```

협업 메커니즘은 놀라울 만큼 단순하다. 에이전트가 작업을 시작할 때 `current_tasks/parse_if_statement.txt` 같은 파일을 생성해 잠근다. 다른 에이전트는 그 파일이 존재하면 해당 작업을 건드리지 않는다. 별도 오케스트레이터 없이 Git이 중재자 역할을 한다.

역할 전문화도 이루어졌다.

| 역할 | 담당 업무 |
|---|---|
| 기능 구현 에이전트 | 파서, 코드 제너레이터 등 핵심 기능 개발 |
| 중복 제거 에이전트 | 동일 기능 재구현 통합 |
| 성능 최적화 에이전트 | 컴파일러 실행 속도 개선 |
| 문서화 에이전트 | README, 아키텍처 문서 유지보수 |

## 이 단계에서 중요한 판단 기준

에이전트의 성능은 모델의 지능이 아니라 테스트 환경의 품질에 의해 결정된다. "AI가 이 테스트 결과만 보고 다음에 뭘 해야 할지 판단할 수 있는가?"라는 기준으로 테스트를 설계해야 한다.

한계도 명확하다. CCC가 모든 최적화를 켜고 생성한 바이너리가 GCC가 최적화를 끈 상태보다 느리다. 10만 줄을 넘어서자 새 기능 추가 시 기존 기능이 깨지는 빈도가 급증했다. 테스트가 통과한다고 작업이 끝난 것이 아니라는 점, 자율 개발에는 새로운 차원의 검증이 필요하다는 점을 잊지 말아야 한다.

## 한 줄 요약 — 이것만 기억하면 된다

**개발자의 핵심 역량이 코드를 작성하는 능력에서 AI가 올바르게 작동할 수 있는 시스템을 설계하는 능력으로 이동하고 있다.**

## 나중에 더 깊게 들어가면

- Git 락 파일 기반 에이전트 협업 프로토콜 구현 방법
