> 이 주에 드러난 핵심 패턴은 하나다. AI 도구들이 "단독 실행"에서 "통합·표준화·에이전트화"로 빠르게 이동하고 있다.

---

## 이번 주 변화를 왜 이해해야 하는지 감 잡기

2025년 10월 셋째 주 AI 업계 뉴스를 보면 개별 사건이 아니라 하나의 방향을 가리킨다. AI 도구들이 API 수준의 단독 기능에서 벗어나, 개발 워크플로우 전체에 내장되는 인프라로 바뀌고 있다. Claude Code 플러그인, 원격 MCP, GitHub Copilot 에이전트 모드, OpenAI AgentKit이 같은 주에 등장한 것은 우연이 아니다.

이 변화를 이해하면 개별 도구 사용법이 아니라, 앞으로 어떤 도구 조합이 표준이 될지 판단하는 안목이 생긴다.

초보자는 이렇게 이해하면 된다.

`핵심 흐름: 단독 AI 도구 → 표준 프로토콜(MCP)로 연결 → 에이전트가 워크플로우 전체를 자율 수행`

## 외워야 할 핵심 용어 5개

| 용어 | 초보자식 설명 |
|---|---|
| MCP (Model Context Protocol) | AI가 외부 도구·데이터에 접근하는 표준 방식. USB-C처럼 어느 AI에나 꽂힌다 |
| 원격 MCP 서버 | 로컬에 설치하지 않고 URL만 추가하면 연결되는 MCP 서버. 설정 부담을 없앤다 |
| 에이전트 모드 | AI가 이슈나 작업을 받아 처음부터 끝까지 자율적으로 처리하는 실행 방식 |
| 플러그인 마켓플레이스 | Git 저장소 기반으로 누구나 배포하고 설치할 수 있는 도구 공유 생태계 |
| AgentKit | OpenAI가 공개한 에이전트 시각적 설계·배포 플랫폼 |

## 예를 들어 설명하면

이번 주 주요 뉴스를 구조적 패턴으로 분류하면 이렇다.

| 패턴 | 이번 주 사례 |
|---|---|
| AI 도구의 표준화 | Claude Code 원격 MCP 지원, OpenAI Apps SDK의 MCP 채택 |
| 워크플로우 통합 | GitHub Copilot 에이전트 모드(이슈 → 코드 → PR 자동화) |
| 에코시스템 확장 | Claude Code 플러그인 공개 베타, Salesforce의 Slack MCP 기업 배포 |
| 경량·속도 모델 진입 | Claude Haiku 4.5가 GitHub Copilot에 통합 |

특히 MCP는 작년 Anthropic이 공개할 때 실험적 기술이었으나, 현재 413개 이상의 클라이언트가 지원하고 OpenAI도 채택했다. 사실상 AI 도구 간 연결의 표준이 됐다.

## 이 단계에서 중요한 판단 기준

새로운 AI 도구를 평가할 때 "MCP를 지원하는가?"를 먼저 확인하라. 지원하지 않으면 다른 도구와 연결하는 데 별도 구현이 필요해 장기적으로 유지보수 부담이 커진다.

## 한 줄 요약 — 이것만 기억하면 된다

**2025년 10월 현재, AI 도구 선택 기준은 "단독 성능"에서 "표준 프로토콜로 연결되는가"로 이동했다.**

## 나중에 더 깊게 들어가면

- MCP 서버 직접 만들기: 사내 도구를 AI에 연결하는 방법
- GitHub Copilot 에이전트 모드 vs Claude Code 에이전트: 적합한 작업 유형 비교
- TypeScript 컴파일러 Go 재작성(`tsgo`): 개발 도구 성능 개선의 실제 영향
