> **TL;DR**
> GPT는 수십억 개의 문장을 미리 학습한 뒤, 입력된 문맥에 맞는 다음 단어를 확률적으로 생성하는 언어 모델이다.

---

## GPT를 왜 쓰는지 감 잡기

기존 챗봇은 질문-답변 쌍을 데이터베이스에 넣어두고 매칭한다. 질문이 조금만 달라져도 답을 못 찾는다. GPT는 접근 방식이 다르다. 인터넷과 책에서 수집한 방대한 텍스트로 언어 패턴을 학습해, 처음 보는 질문에도 문맥에 맞는 답을 만들어낸다.

사용처는 코드 작성 보조, 번역, 요약, 질의응답, 창작 글쓰기까지 언어가 필요한 거의 모든 분야에 걸쳐 있다.

초보자는 처음에 이렇게 이해하면 된다.

`핵심 흐름: 대규모 텍스트 사전학습 → 문맥 이해(Transformer) → 다음 토큰 생성 → 응답 완성`

## 외워야 할 핵심 용어 5개

| 용어 | 초보자식 설명 |
|---|---|
| Generative(생성형) | 질문에 답하는 것을 넘어, 새로운 문장을 직접 만들어낸다는 의미. |
| Pre-trained(사전학습) | 사용자와 대화하기 전에, 이미 수백 GB의 텍스트로 언어를 익혀둔 상태. |
| Transformer | GPT가 사용하는 신경망 구조. 문장 안 각 단어가 다른 단어들과 어떤 관계인지 동시에 계산한다. |
| Attention(어텐션) | Transformer 내부 메커니즘. "이 단어를 이해하려면 문장의 어느 부분을 주목해야 하는가"를 학습한다. |
| Fine-tuning(미세조정) | 사전학습된 모델을 특정 목적(코드 작성, 고객 응대 등)에 맞게 추가로 훈련하는 과정. |

## 예를 들어 설명하면

"프랑스의 수도는 어디야?"라고 묻는다고 하자. GPT는 인터넷을 검색하지 않는다. 사전학습 중에 "프랑스"와 "파리"가 수없이 같은 문맥에서 등장했기 때문에, 모델 내부 가중치에 그 연관성이 이미 녹아 있다.

이어서 "파리를 배경으로 단편 소설을 써줘"라고 하면, 같은 모델이 생성 능력을 써서 완전히 새로운 텍스트를 만들어낸다. 이것이 "Pre-trained"와 "Generative"가 결합된 GPT의 작동 방식이다.

## 이 단계에서 중요한 판단 기준

GPT는 학습 데이터의 마감 시점 이후 정보를 모른다. 실시간 정보가 필요한 작업에는 검색 연동(RAG) 같은 별도 장치가 필요하다.

## 한 줄 요약 — 이것만 기억하면 된다

**GPT는 "다음에 올 단어를 예측하는 훈련"을 통해 언어를 이해하고, 그 능력으로 새 텍스트를 생성한다.**

## 나중에 더 깊게 들어가면

- RLHF(인간 피드백 강화학습): GPT를 사람의 선호에 맞게 조정하는 방법
- 토큰과 컨텍스트 윈도우: 한 번에 처리할 수 있는 텍스트 길이의 한계
- RAG(검색 증강 생성): 외부 문서를 실시간으로 참조해 답변 정확도를 높이는 기법
