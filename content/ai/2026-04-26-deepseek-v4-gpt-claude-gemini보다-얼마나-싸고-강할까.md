> **TL;DR**
> DeepSeek V4의 핵심은 최고 성능 단독 1위가 아니라, 1M 컨텍스트와 상위권 추론 성능을 매우 낮은 토큰 단가로 제공하는 가격 효율이다.

---

## DeepSeek V4를 왜 주목해야 하는지 감 잡기

AI 모델을 고를 때 벤치마크 순위만 보면 실제 비용을 놓친다. 같은 품질을 내는 데 얼마가 드는지, 이전 모델보다 효율이 얼마나 좋아졌는지가 현장에서 더 중요하다. DeepSeek V4는 Flash와 Pro 두 라인업으로 나뉜다. Flash는 빠르고 저렴한 대량 처리용, Pro는 고성능 추론과 코딩·에이전트 작업용이다. 두 모델 모두 1M 컨텍스트와 최대 384K 출력 토큰을 지원한다.

초보자는 처음에 이렇게 이해하면 된다.

`핵심 흐름: 작업 유형 파악 → Flash(대량·저가) 또는 Pro(추론·코딩) 선택 → 실제 사용량 기준으로 비용 계산`

## 외워야 할 핵심 용어 5개

| 용어 | 초보자식 설명 |
|---|---|
| 입력 토큰 단가 | 모델에 보내는 텍스트 1백만 자 기준 요금. 프롬프트가 길수록 이 비용이 커진다. |
| 출력 토큰 단가 | 모델이 생성하는 텍스트 1백만 자 기준 요금. 에이전트나 코딩 작업은 답변이 길어 이 비용이 더 크게 체감된다. |
| 오픈웨이트 | 모델 가중치(내부 파라미터)를 공개해 누구나 자체 서버에서 실행할 수 있는 방식. 클라우드 API 외에 선택지가 생긴다. |
| KV 캐시 | 반복되는 프롬프트 앞부분을 재계산하지 않고 재사용해 비용을 줄이는 기술. 캐시 히트가 많을수록 실제 청구 비용이 낮아진다. |
| Intelligence Index | Artificial Analysis가 발표하는 모델 종합 성능 점수. 벤치마크를 하나로 통합한 참고 지표다. |

## 예를 들어 설명하면

월간 입력 100M 토큰, 출력 20M 토큰을 사용한다고 가정한 단순 비용 비교다 (캐시·이미지·음성 비용 제외).

| 모델 | 입력 $/1M | 출력 $/1M | 월 예상 비용 |
|---|---|---|---|
| DeepSeek V4-Flash | $0.14 | $0.28 | 약 $19.60 |
| DeepSeek V4-Pro 할인가 | $0.435 | $0.87 | 약 $60.90 |
| DeepSeek V4-Pro 정가 | $1.74 | $3.48 | 약 $243.60 |
| GPT-5.5 | $5.00 | $30.00 | 약 $1,100 |
| Claude Opus 4.7 | $5.00 | $25.00 | 약 $1,000 |
| Gemini 3.1 Pro Standard (200K 초과) | $2~$4 | $12~$18 | 약 $760 |

V4-Flash는 GPT-5.5 대비 출력 단가가 약 107배 저렴하다. 에이전트·코딩처럼 답변이 긴 작업일수록 출력 비용이 지배적으로 작용하므로, 이 차이가 실제로 크게 체감된다.

## 이 단계에서 중요한 판단 기준

DeepSeek V4-Pro는 토큰 단가는 싸지만, 고난도 추론에서 출력 토큰을 많이 쓰면 총비용이 생각보다 커질 수 있다. Artificial Analysis 기준 V4-Pro의 Intelligence Index 전체 실행 비용은 $1,071로, V3.2의 $71보다 훨씬 높다.

벤치마크에서 두드러지는 항목은 코딩이다. LiveCodeBench(93.5)와 Codeforces Rating(3206)은 비교 대상 중 가장 높다. 반면 GPQA Diamond, SimpleQA Verified, MMLU-Pro에서는 Gemini 3.1 Pro나 GPT-5.4가 앞서는 항목이 있어, 전 벤치마크 일괄 우세라고 보기는 어렵다.

| 사용 패턴 | 추천 모델 | 주의점 |
|---|---|---|
| 대량 요약·분류·반복 응답 | V4-Flash | 복잡한 추론은 Pro 대비 약할 수 있음 |
| 코딩·에이전트·복잡한 분석 | V4-Pro | Think Max 사용 시 출력 토큰 증가로 총비용 상승 |
| 1차 처리 후 최종 검토 | Flash → Pro 파이프라인 | 파이프라인 설계 필요 |
| 긴 문서 분석 | V4 우선 테스트 | 텍스트 중심 모델, 멀티모달 한계 있음 |
| 멀티모달·기업 안정성 | GPT·Claude·Gemini 유지 | 출력 단가가 높아 대량 사용 시 비용 부담 |

## 한 줄 요약 — 이것만 기억하면 된다

**DeepSeek V4-Flash는 대량 처리 비용 절감용, V4-Pro는 코딩·추론에서 오픈웨이트 상위권 성능을 낮은 단가로 쓰는 선택지다. 단, 실제 비용은 반드시 사용량 기준으로 계산해야 한다.**

## 나중에 더 깊게 들어가면

- KV 캐시 히트를 높이기 위한 프롬프트 설계 전략
- 오픈웨이트 V4-Pro를 자체 서버에서 실행하는 요건과 비용 비교
- DeepSeek V3.2 대비 V4에서 실제로 성능이 낮아진 벤치마크 항목 분석 (BigCodeBench 등)
