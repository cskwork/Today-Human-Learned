## ChatGPT를 왜 쓰는지 감 잡기

GPT는 수천억 개의 텍스트 데이터로 학습한 언어 모델이다. 이 모델은 다음에 올 단어를 예측하는 방식으로 작동하는데,
그 능력이 충분히 발전하자 질문에 답하고, 코드를 짜고, 문서를 요약하는 수준에 도달했다.
ChatGPT는 이 모델에 대화 인터페이스를 얹어 일반 사용자도 쓸 수 있게 만든 제품이다.

GPT와 ChatGPT의 관계는 엔진과 자동차의 관계와 비슷하다.
GPT가 엔진이라면, ChatGPT는 운전대와 계기판을 갖춘 완성차다.

`핵심 흐름: 사용자 입력 -> 프롬프트 구성 -> GPT 추론 -> 텍스트 출력`

## 외워야 할 핵심 용어 5개

| 용어 | 초보자식 설명 |
|---|---|
| GPT | Generative Pre-trained Transformer. 대량의 텍스트로 사전 학습된 언어 생성 모델 |
| 프롬프트 | 모델에 전달하는 입력 텍스트. 질문, 지시, 예시 등 어떤 형태든 될 수 있다 |
| 컨텍스트 창 | 모델이 한 번에 기억할 수 있는 텍스트 범위. 이 범위를 넘으면 초반 내용을 잊는다 |
| 파인튜닝 | 특정 도메인 데이터로 기존 모델을 추가 학습시켜 전문화하는 과정 |
| GPTs | OpenAI가 제공하는 커스텀 ChatGPT. 특정 목적(법률, 의료, 코딩 등)에 맞게 설정된 버전 |

## 예를 들어 설명하면

ChatGPT로 Python 파일 읽기 코드를 작성하는 상호작용이다.

```
사용자: "파일을 읽고 내용을 출력하는 Python 코드를 보여줘."

ChatGPT:
with open('example.txt', 'r') as file:
    contents = file.read()
    print(contents)

with open은 파일을 열고, 블록이 끝나면 자동으로 닫는다.
예외가 발생해도 파일이 정상적으로 닫히는 것을 보장한다.
```

핵심은 질문을 구체적으로 할수록 답변의 품질이 높아진다는 것이다.
"코드 보여줘"보다 "Python 3.11에서 UTF-8 파일을 읽어 줄 단위로 출력하는 코드 보여줘"가 낫다.

## 이 단계에서 중요한 판단 기준

ChatGPT의 출력은 확률적이다. 사실처럼 보이는 틀린 답(할루시네이션)이 나올 수 있으므로, 중요한 정보는 반드시 원본 소스로 검증해야 한다.
