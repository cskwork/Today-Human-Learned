> **TL;DR**
> Panorama는 분산된 학생 데이터를 Claude로 실시간 통합해 교사가 자연어로 질문하면 개인화된 개입 계획을 수 초 안에 받을 수 있게 했고, 학생 데이터는 외부에 유출되지 않는다.

---

## 교육 AI를 왜 쓰는지 감 잡기

미국 K-12 교육 현장에서 교사는 학생 한 명의 상황을 파악하려면 성적 시스템, 출결 기록, 설문 결과를 각각 다른 도구에서 열어야 한다. 14,400개 학군이 독립적으로 운영되고 시스템이 연결되지 않아, 위험 학생을 조기에 발견하기가 어렵다.

전국 학생의 20%가 수업일의 10% 이상을 결석한다. 조기에 감지하고 개입하면 성적 하락을 막을 수 있지만, 교사가 직접 데이터를 취합하고 계획을 세우는 데 수 시간이 걸렸다.

`교사 자연어 질문 → AI가 분산 데이터 실시간 통합 → 패턴 분석 → 개인화 개입 계획 제안 → 교사 검토 후 실행`

## 외워야 할 핵심 용어 5개

| 용어 | 초보자식 설명 |
|---|---|
| Solara | Panorama가 Claude 기반으로 만든 교사용 AI 플랫폼 이름 |
| SMART 목표 | 구체적·측정 가능·달성 가능·관련성·기한이 명시된 목표 작성 방식 |
| Stateless 설계 | AI가 응답을 생성한 후 학생 데이터를 즉시 폐기해서 외부 학습에 쓰이지 않는 구조 |
| Bedrock Guardrails | AI 응답에서 부적절한 내용을 자동으로 차단하는 AWS 안전 장치 |
| FERPA | 미국 학생 교육 기록 보호법. 교육 AI가 반드시 준수해야 하는 개인정보 규정 |

## 예를 들어 설명하면

교사가 Solara에서 "이 학생 어디를 도와야 해?"라고 입력하면:

1. 출결, 성적, 행동 기록, 설문 데이터를 실시간으로 통합
2. 패턴 분석 (예: 최근 결석 증가와 수학 성적 하락의 상관관계 감지)
3. SMART 목표가 포함된 개인화 개입 계획 제안

Panorama가 Claude를 선택한 이유는 성능, 보안, 프라이버시 세 가지였다. Amazon Bedrock의 stateless 설계 덕분에 학생 데이터가 응답 생성 이후 즉시 폐기되어 외부 모델 학습에 사용되지 않는다. SOC2, FERPA, COPPA 인증을 모두 충족한다.

| 자동 생성 도구 | 기능 |
|---|---|
| Personalized Attendance Plan | 결석 개선 계획 (SMART 목표 포함) |
| Family Nudge Letter | 학생 상황에 맞춘 가정 통신문 |
| Tier 1 Differentiation | 수준별·특수 요구 반영 수업 조정안 |

## 이 단계에서 중요한 판단 기준

교육 AI에서 기술 선택의 핵심은 데이터 보호와 AI 성능을 동시에 달성하는 구조다. stateless 설계가 이 둘을 양립시키는 핵심 원칙이다.

## 한 줄 요약 — 이것만 기억하면 된다

**Panorama의 성공은 AI 도입 자체가 아니라, 교사의 기존 워크플로에 AI를 자연스럽게 녹여서 새로운 부담 없이 수시간 걸리던 데이터 분석을 수 초로 단축한 설계에 있다.**

## 나중에 더 깊게 들어가면

- Amazon Bedrock stateless 설계와 KMS 암호화를 활용한 교육 데이터 보호 구조
- 14,400개 독립 학군에 동일한 AI 플랫폼을 배포하는 멀티 테넌트 설계 패턴
- FERPA·COPPA 준수 AI 시스템의 접근 제어(RBAC) 설계
