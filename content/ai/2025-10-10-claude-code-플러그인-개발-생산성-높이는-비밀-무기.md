## Claude Code 플러그인을 왜 쓰는지 감 잡기

Claude Code는 터미널에서 작동하는 AI 개발 도구다. 혼자 쓸 때는 커스텀 명령어 하나 추가하는 게 어렵지 않다. 문제는 팀 전체가 동일한 설정을 공유하려 할 때다. 파일을 복사하고, 디렉토리 구조를 설명하고, 팀원마다 수동으로 설정해야 한다. 그리고 누군가 개선하면 또 전파해야 한다.

플러그인 시스템은 이 문제를 해결한다. 슬래시 커맨드, 서브에이전트, MCP 서버, 훅을 하나의 패키지로 묶고, Git 저장소를 마켓플레이스로 삼아 `/plugin install` 한 줄로 설치한다. 2025년 10월 공개 베타로 출시됐다.

초보자는 이렇게 이해하면 된다.

`핵심 흐름: 마켓플레이스 추가 → 플러그인 설치 → 팀 저장소에 설정 커밋 → 팀 전체 자동 적용`

## 외워야 할 핵심 용어 5개

| 용어 | 초보자식 설명 |
|---|---|
| 플러그인 | 슬래시 커맨드, 에이전트, MCP 서버, 훅을 하나로 묶은 설치 가능한 확장 패키지 |
| 마켓플레이스 | Git 저장소 기반의 플러그인 카탈로그. 누구나 만들어 호스팅할 수 있다 |
| 슬래시 커맨드 | `/deploy`처럼 `/`로 시작하는 단축 명령어. 반복 작업을 자동화한다 |
| 서브에이전트 | 코드 리뷰, 보안 검증, 문서 작성 등 특정 역할에 특화된 전문 AI |
| 훅(Hook) | PR 생성이나 커밋 같은 특정 이벤트가 발생할 때 자동으로 실행되는 스크립트 |

## 예를 들어 설명하면

팀 전체에 플러그인을 배포하려면 프로젝트 저장소에 `.claude/settings.json`을 추가한다.

```json
{
  "extraKnownMarketplaces": {
    "team-tools": {
      "source": {
        "source": "github",
        "repo": "your-org/claude-plugins"
      }
    }
  },
  "enabledPlugins": ["code-formatter", "deployment-tools", "test-suite"]
}
```

팀원이 이 저장소를 클론하면 Claude Code가 지정된 마켓플레이스와 플러그인을 자동으로 설치한다. 별도 설정 없이 동일한 개발 환경을 갖추게 된다.

## 이 단계에서 중요한 판단 기준

플러그인은 필요한 것만 켜야 한다. 활성화된 플러그인이 많아질수록 시스템 프롬프트 컨텍스트가 늘어나 성능과 비용에 영향을 준다.

## 한 줄 요약 — 이것만 기억하면 된다

**Claude Code 플러그인은 커스텀 워크플로우를 패키징하고 팀 전체에 한 줄로 배포하는 인프라다.**

## 나중에 더 깊게 들어가면

- 커스텀 플러그인 제작: `plugin.json` 매니페스트 구조와 명령어 파일 작성
- MCP 서버 플러그인: GitHub API, Slack 등 외부 시스템 연동
- 훅 기반 자동화: 무한 루프 방지 로직과 실패 시 롤백 전략
