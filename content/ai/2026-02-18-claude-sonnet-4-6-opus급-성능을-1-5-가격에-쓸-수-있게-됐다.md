## Sonnet 4.6을 왜 주목해야 하는지 감 잡기

AI 모델 시장에서 오랫동안 통용되던 공식이 있었다. 비싼 모델(Opus)은 성능이 좋고, 중간 모델(Sonnet)은 가격이 적당하고, 경량 모델(Haiku)은 빠르다는 3단 구조다. 깊은 추론이나 복잡한 코딩은 Opus에 맡기고 일상 업무에 Sonnet을 쓰는 것이 일반적인 전략이었다.

2026년 2월 17일 출시된 Sonnet 4.6은 이 공식을 뒤집는다. Opus 4.6 출시 불과 12일 뒤에 등장한 이 모델은 대부분의 벤치마크에서 Opus와의 격차를 0.2~1.2%p 수준으로 좁혔다. 일부 영역에서는 역전이 일어났다.

가격은 그대로다. 입력 100만 토큰당 $3, 출력 100만 토큰당 $15. Opus 4.6의 $15/$75와 비교하면 정확히 1/5 수준이다.

`핵심 흐름: 중간 모델 → 플래그십 수준 성능 → 1/5 가격 → 기업 대규모 배포 경제적으로 가능`

## 외워야 할 핵심 용어 5개

| 용어 | 초보자식 설명 |
|---|---|
| OSWorld | AI가 실제 컴퓨터를 마우스/키보드로 조작하는 능력을 측정하는 벤치마크. 점수가 높을수록 복잡한 GUI 작업을 잘 처리한다. |
| SWE-bench | AI가 실제 소프트웨어 버그를 코드로 수정하는 능력을 측정하는 벤치마크. |
| 컴퓨터 사용(Computer Use) | AI가 사람처럼 화면을 보고 마우스를 클릭하며 앱을 조작하는 기술. API가 없는 레거시 소프트웨어 자동화에 쓰인다. |
| Adaptive Thinking | 문제 복잡도에 따라 사고 깊이를 자동으로 조절하는 Sonnet 4.6의 추론 모드. |
| Context Compaction | 대화가 길어지면 이전 컨텍스트를 자동으로 요약해 사실상 무한 대화를 가능하게 하는 베타 기능. |

## 예를 들어 설명하면

벤치마크 수치로 Opus와의 차이를 확인할 수 있다.

| 벤치마크 | Sonnet 4.6 | Opus 4.6 |
|---|---|---|
| OSWorld-Verified (컴퓨터 사용) | 72.5% | 72.7% |
| SWE-bench Verified (코딩) | 79.6% | 80.8% |
| ARC-AGI-2 (추상 추론) | 60.4% | 68.8% |
| GDPval-AA (사무 업무) | 1633 Elo | 1559 Elo |
| Finance Agent (금융 분석) | 63.3% | — |

컴퓨터 사용 능력의 발전 속도도 주목할 만하다. OSWorld 점수가 2024년 10월 Sonnet 3.5의 14.9%에서 Sonnet 4.6의 72.5%로 16개월 만에 약 5배 뛰었다.

Claude Code 사용자 자체 테스트에서도 70%가 Sonnet 4.5보다, 59%가 Opus 4.5보다 Sonnet 4.6을 선호했다. 과도한 엔지니어링이 줄고 지시사항 이행이 더 정확해졌다는 평가가 주를 이뤘다.

## 이 단계에서 중요한 판단 기준

사무 업무, 금융 분석, 컴퓨터 사용 자동화, 일반 코딩에는 Sonnet 4.6이 더 합리적이다. 복잡한 에이전트 워크플로우나 코드베이스 전체 리팩토링처럼 깊은 추론이 필요한 작업에만 Opus 4.6을 고려한다.

## 한 줄 요약 — 이것만 기억하면 된다

**Sonnet 4.6은 사무·분석 업무에서 Opus를 앞서는 성능을 1/5 가격에 제공하므로, Opus를 기본으로 쓰던 팀은 즉시 전환을 검토할 만하다.**

- Sonnet 4.6의 100만 토큰 컨텍스트 윈도우 활용 전략
- 프롬프트 인젝션 방어 메커니즘과 컴퓨터 사용 기능의 보안 고려사항
