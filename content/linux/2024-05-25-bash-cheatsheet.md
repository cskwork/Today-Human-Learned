> **TL;DR**
> Bash는 리눅스 쉘 스크립트의 기본 언어다. 단축키, 변수, 흐름 제어, 리다이렉션 네 가지 개념만 잡으면 실무에서 쓸 수 있다.

---

## Bash를 왜 배우는지 감 잡기

서버에서 반복 작업을 자동화하거나, 여러 명령을 조합해서 하나의 스크립트로 만들 때 Bash를 쓴다. Python이나 다른 언어도 가능하지만, 리눅스 시스템 자체가 Bash 기반으로 돌아가기 때문에 Bash를 모르면 서버에서 일하기 불편하다. 설치 없이 어느 리눅스 서버에서나 바로 쓸 수 있다는 점이 강점이다.

초보자는 처음에 이렇게 이해하면 된다.

`핵심 흐름: 명령어 입력 → 변수로 값 저장 → 조건/반복으로 흐름 제어 → 결과를 파일로 출력`

## 외워야 할 핵심 용어 5개

| 용어 | 초보자식 설명 |
|---|---|
| 변수 | `varname=value`로 값을 저장하고, `$varname`으로 꺼내 쓴다. |
| 리다이렉션 | `>` 는 출력을 파일로 저장, `>>` 는 파일에 추가, `|` 는 다음 명령으로 전달. |
| 환경변수 | `export`로 선언하면 자식 프로세스에서도 접근할 수 있는 변수. |
| 종료 코드 | `$?`로 확인. 0이면 성공, 그 외는 오류. |
| 커맨드 히스토리 | `history`로 전체 조회, `!!`로 마지막 명령 재실행. |

## 예를 들어 설명하면

```bash
# 변수 선언과 사용
name="world"
echo "Hello, $name"

# 파일로 리다이렉션
echo "log start" > run.log     # 덮어쓰기
echo "step 1 done" >> run.log  # 추가

# 조건문
if [ -f "config.yml" ]; then
  echo "설정 파일 있음"
else
  echo "설정 파일 없음"
fi

# 반복문
for i in {1..5}; do
  echo "step $i"
done

# 명령 결과를 변수에 저장
current_dir=$(pwd)
echo "현재 위치: $current_dir"

# 자주 쓰는 단축키
# CTRL+C : 실행 중인 명령 중단
# CTRL+R : 이전 명령 검색
# CTRL+L : 화면 지우기
```

## 이 단계에서 중요한 판단 기준

스크립트 첫 줄에 `#!/bin/bash`를 붙이고, 실행 전에 `bash -n 스크립트.sh`로 문법 오류를 먼저 확인한다.

## 한 줄 요약 — 이것만 기억하면 된다

**변수는 `$`, 출력은 `>`, 조합은 `|`, 반복은 `for`/`while`, 이 네 가지가 Bash의 뼈대다.**

## 나중에 더 깊게 들어가면

- 함수 정의와 인자 전달 (`$1`, `$2`, `$@`)
- `set -e`로 오류 발생 시 스크립트 즉시 종료하기
- `trap`으로 스크립트 종료 시 정리 작업 처리하기
