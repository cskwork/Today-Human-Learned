> **TL;DR**
> Vim은 모드 기반 편집기다. Normal 모드와 Insert 모드의 차이만 이해하면 기본 편집은 바로 가능하다.

---

## Vim을 왜 배우는지 감 잡기

서버에 SSH로 접속하면 GUI 편집기가 없다. 이때 거의 모든 리눅스 서버에 기본으로 설치된 편집기가 Vim이다. 처음에는 낯설지만, 모드 개념만 이해하면 설정 파일 수정 정도는 금방 할 수 있다. 마우스 없이 키보드만으로 빠르게 텍스트를 편집하는 방식이 핵심이다.

초보자는 처음에 이렇게 이해하면 된다.

`핵심 흐름: Vim 열기 → Normal 모드 → i로 Insert 모드 진입 → 편집 → Esc로 Normal 복귀 → :wq로 저장 후 종료`

## 외워야 할 핵심 용어 5개

| 용어 | 초보자식 설명 |
|---|---|
| Normal 모드 | Vim 기본 상태. 커서 이동과 명령 입력용. 키를 눌러도 글자가 입력되지 않는다. |
| Insert 모드 | 글자를 실제로 입력할 수 있는 상태. `i`를 누르면 진입, `Esc`로 나간다. |
| Visual 모드 | 텍스트를 선택할 수 있는 상태. `v`로 진입. |
| 버퍼 | Vim에서 열린 파일 하나를 가리키는 단위. 여러 파일을 동시에 열 수 있다. |
| register | 복사(yank)한 텍스트가 저장되는 공간. `p`로 붙여넣기. |

## 예를 들어 설명하면

```
# 가장 자주 쓰는 명령 모음

커서 이동 (Normal 모드)
  h j k l    좌 하 상 우
  gg         파일 첫 줄로 이동
  G          파일 마지막 줄로 이동
  :42        42번째 줄로 이동

편집 (Normal 모드에서)
  i          커서 앞에서 Insert 모드 진입
  o          현재 줄 아래 새 줄 추가하며 Insert 모드
  dd         현재 줄 삭제(잘라내기)
  yy         현재 줄 복사
  p          붙여넣기
  u          실행 취소 (undo)
  CTRL-r     다시 실행 (redo)

검색과 치환
  /단어      단어 검색 (n으로 다음 결과)
  :%s/old/new/g   파일 전체에서 old를 new로 교체

저장과 종료
  :w         저장
  :q         종료 (변경 없을 때)
  :wq        저장 후 종료
  :q!        저장 없이 강제 종료
```

## 이 단계에서 중요한 판단 기준

Vim에서 막혔을 때는 `Esc`를 여러 번 눌러 Normal 모드로 돌아온 뒤, `:q!`로 저장 없이 나오는 것이 가장 안전하다.

## 한 줄 요약 — 이것만 기억하면 된다

**`i`로 편집 시작, `Esc`로 Normal 복귀, `:wq`로 저장 종료 — 이 세 가지만 기억하면 서버에서 파일 수정은 가능하다.**

## 나중에 더 깊게 들어가면

- 매크로(`qa ... q`, `@a`)로 반복 작업 자동화하기
- `.vimrc` 설정 파일로 Vim 환경 커스터마이징하기
