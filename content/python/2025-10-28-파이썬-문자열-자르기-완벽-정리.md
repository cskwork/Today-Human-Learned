> 고정 위치로 자르면 슬라이싱, 구분자로 여러 조각을 내면 `split`, 첫 번째 구분자 기준으로 딱 한 번만 나누면 `partition`이다.

---

## 문자열 자르기를 왜 쓰는지 감 잡기

파일 경로에서 확장자를 떼거나, 로그 줄에서 날짜만 뽑거나, CSV 한 줄을 필드로 분해할 때 문자열 자르기는 필수다. Python은 슬라이싱, `split`, `partition`, 정규표현식 등 여러 방법을 제공하는데, 상황에 맞게 선택하지 않으면 코드가 불필요하게 복잡해진다.

초보자는 처음에 이렇게 이해하면 된다.

`핵심 흐름: 자르기 방식 선택(위치/구분자/패턴) → 메서드 적용 → 잘린 결과 사용`

## 외워야 할 핵심 용어 5개

| 용어 | 초보자식 설명 |
|---|---|
| 슬라이싱 `s[start:end:step]` | 인덱스 범위로 문자열 일부를 추출. `s[1:4]`는 1번부터 3번까지 |
| `split(sep, maxsplit)` | 구분자(`sep`)로 문자열을 나눠 리스트로 반환. `maxsplit`으로 횟수 제한 가능 |
| `partition(sep)` | 첫 번째 구분자를 기준으로 `(앞, 구분자, 뒤)` 세 요소 튜플을 반환 |
| `strip()` | 문자열 양쪽 끝의 공백이나 지정 문자를 제거 |
| 음수 인덱스 | `s[-1]`은 마지막 글자, `s[-4:]`는 뒤에서 네 글자. 길이를 몰라도 끝에서 접근 가능 |

## 예를 들어 설명하면

```python
text = "Python3.11"

# 슬라이싱 — 위치가 고정된 경우
print(text[0:6])    # Python
print(text[-4:])    # 3.11
print(text[::-1])   # 11.3nohtyP (역순)

# split — 구분자로 여러 조각
log = "2025-10-28 ERROR connection failed"
parts = log.split(' ', 2)
# ['2025-10-28', 'ERROR', 'connection failed']

# partition — 딱 한 번만 나눌 때
email = "user@example.com"
username, _, domain = email.partition('@')
# username = 'user', domain = 'example.com'

# rpartition — 마지막 구분자 기준
path = "data.backup.tar.gz"
name, _, ext = path.rpartition('.')
# name = 'data.backup.tar', ext = 'gz'
```

## 이 단계에서 중요한 판단 기준

| 상황 | 선택 |
|---|---|
| 고정 위치, 인덱스를 안다 | 슬라이싱 `[:]` |
| 구분자가 여러 번 나온다 | `split()` |
| 구분자가 한 번만 나온다(또는 첫/마지막 기준) | `partition()` / `rpartition()` |
| 복잡한 패턴 (날짜, 이메일 형식 등) | `re.split()` / `re.findall()` |

정규표현식은 성능이 느리고 읽기 어려우므로 단순 구분자에는 쓰지 않는다.

## 한 줄 요약 — 이것만 기억하면 된다

**파일명-확장자는 `rpartition('.')`, CSV 파싱은 `split(',')`, 고정 길이는 슬라이싱이 정석이다.**

## 나중에 더 깊게 들어가면

- `re.split(r'[;,:]', text)` — 복수 구분자를 한 번에 처리하는 정규표현식 split
- `str.removeprefix()` / `str.removesuffix()` — Python 3.9+ 접두사·접미사 제거 전용 메서드
- 유니코드 문자열 슬라이싱 주의점 (서로게이트 페어, 결합 문자)
