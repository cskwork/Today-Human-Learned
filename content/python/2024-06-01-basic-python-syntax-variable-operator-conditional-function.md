## Python 기본 문법을 왜 쓰는지 감 잡기

코드는 데이터를 담고, 계산하고, 조건에 따라 다르게 행동하고, 반복 가능한 단위로 묶는 과정이다. 이 네 가지 동작이 프로그래밍의 대부분을 차지한다. Python은 이 요소들을 영어와 가까운 문법으로 표현해, 처음 배우는 사람도 코드를 읽으면서 의미를 파악할 수 있다.

실생활로 보면 변수는 메모장, 연산자는 계산기, 조건문은 신호등, 함수는 레시피에 해당한다.

`핵심 흐름: 값 저장(변수) → 값 조작(연산자) → 흐름 결정(조건문) → 로직 재사용(함수)`

## 외워야 할 핵심 용어 5개

| 용어 | 초보자식 설명 |
|---|---|
| 변수 | 값을 담아두는 이름표. `age = 30`처럼 이름과 값을 연결한다. |
| 자료형 | 변수에 담긴 값의 종류. 정수(int), 소수(float), 문자열(str), 참/거짓(bool)이 기본이다. |
| 연산자 | 값을 계산하거나 비교하는 기호. `+`, `-`, `==`, `>` 등이다. |
| 조건문 | `if / elif / else`로 특정 조건일 때만 실행할 코드를 분기한다. |
| 함수 | `def`로 정의하는 재사용 가능한 코드 블록. 한 번 작성하면 여러 번 호출할 수 있다. |

## 예를 들어 설명하면

사용자 이름과 나이를 입력받아, 성인인지 미성년자인지 판별하는 프로그램이다.

```python
def get_user_info():
    name = input("이름을 입력하세요: ")
    age = int(input("나이를 입력하세요: "))

    if age >= 18:
        print(f"{name}님, 성인입니다.")
    else:
        print(f"{name}님, 미성년자입니다.")

get_user_info()
```

- `name`, `age`는 변수다.
- `int(...)` 는 문자열을 정수 자료형으로 변환하는 연산이다.
- `if / else`가 조건문, `get_user_info()`가 함수 호출이다.

## 이 단계에서 중요한 판단 기준

같은 코드를 두 번 이상 쓰게 된다면 함수로 묶는 것이 맞다. 조건문 중첩이 3단계를 넘어가면 함수로 분리해 가독성을 유지한다.
