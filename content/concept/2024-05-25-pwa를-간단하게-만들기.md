> **TL;DR**
> PWA는 웹 기술(HTML/CSS/JS)만으로 앱 스토어 없이 설치 가능한 앱 경험을 제공하며, 핵심은 manifest.json과 Service Worker 두 파일이다.

---

## PWA를 왜 쓰는지 감 잡기

모바일 사용자는 대부분의 시간을 네이티브 앱에서 보내지만, 절반 이상은 새 앱을 거의 설치하지 않는다. PWA(Progressive Web App)는 이 간극을 메운다. 브라우저로 접속하면 설치 없이 바로 쓸 수 있고, 원하면 홈 화면에 아이콘을 추가해 앱처럼 실행할 수 있다. 오프라인에서도 작동하고, 안드로이드 기기에서는 푸시 알림도 받을 수 있다.

네이티브 앱 개발보다 훨씬 낮은 비용으로 크로스 플랫폼 앱 경험을 줄 수 있다는 점이 PWA의 핵심 가치다.

초보자는 처음에 이렇게 이해하면 된다.

`핵심 흐름: 웹 페이지 방문 → Service Worker 등록 → 캐시 저장 → 오프라인/재방문 시 캐시로 응답`

## 외워야 할 핵심 용어 5개

| 용어 | 초보자식 설명 |
|---|---|
| PWA | 웹 기술로 만든 앱처럼 동작하는 웹사이트 |
| manifest.json | 앱 이름, 아이콘, 시작 URL 등 앱 정보를 담은 설정 파일 |
| Service Worker | 브라우저 백그라운드에서 실행되는 JS. 캐싱과 오프라인 처리를 담당 |
| 캐시(Cache) | 리소스를 브라우저에 미리 저장해 오프라인이나 느린 네트워크에서도 빠르게 로드하는 저장소 |
| HTTPS | Service Worker는 보안 컨텍스트(HTTPS)에서만 작동한다 |

## 예를 들어 설명하면

PWA는 세 파일로 구성된다. 각 파일의 역할을 코드로 확인한다.

**manifest.json** — 앱 메타데이터 선언

```json
{
  "name": "hello-pwa",
  "short_name": "pwa",
  "start_url": "./index.html",
  "display": "standalone",
  "icons": [
    { "src": "images/icon-192.png", "sizes": "192x192", "type": "image/png" },
    { "src": "images/icon-512.png", "sizes": "512x512", "type": "image/png" }
  ]
}
```

**sw.js** — Service Worker: 설치 시 캐시 저장, 이후 오프라인 응답

```js
var cacheName = 'pwacache';
var filesToCache = ['./', './index.html', './js/main.js'];

self.addEventListener('install', function(e) {
  e.waitUntil(caches.open(cacheName).then(c => c.addAll(filesToCache)));
  self.skipWaiting();
});

self.addEventListener('fetch', function(e) {
  e.respondWith(
    caches.match(e.request).then(response => response || fetch(e.request))
  );
});
```

**main.js** — Service Worker 등록

```js
window.onload = () => {
  if ('serviceWorker' in navigator) {
    navigator.serviceWorker.register('./sw.js');
  }
};
```

Service Worker의 경로가 틀리면 등록 자체가 안 된다. sw.js는 제어하려는 범위의 루트에 두어야 한다.

## 이 단계에서 중요한 판단 기준

테스트는 반드시 HTTPS 환경(또는 localhost)에서 해야 한다. GitHub Pages에 올리면 바로 HTTPS가 적용돼 Service Worker를 테스트하기 좋다.

## 한 줄 요약 — 이것만 기억하면 된다

**PWA의 핵심은 manifest.json(앱 정보)과 Service Worker(오프라인 캐시)이며, 이 둘만 제대로 연결하면 웹사이트가 설치 가능한 앱이 된다.**
