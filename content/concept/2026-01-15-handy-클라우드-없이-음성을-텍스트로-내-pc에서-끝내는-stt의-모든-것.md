> **TL;DR**
> Handy는 Whisper와 Parakeet 모델을 로컬에서 실행해 음성 데이터를 외부로 보내지 않고도 실용적인 속도로 텍스트를 변환하는 오픈소스 데스크톱 앱이다.

---

## 로컬 STT를 왜 쓰는지 감 잡기

대부분의 STT 서비스는 클라우드에서 처리한다. 인터넷이 없으면 쓸 수 없고, 내 음성 데이터가 외부 서버를 거친다. 회의 내용이나 의료 상담처럼 민감한 정보를 변환할 때는 데이터가 제3자 인프라에 전송된다는 사실이 문제가 된다. 2022년 OpenAI가 Whisper를 오픈소스로 공개하면서 상업 서비스에 견줄 만한 정확도의 로컬 STT가 가능해졌다. Handy는 이 모델을 비기술자도 바로 쓸 수 있는 데스크톱 앱으로 포장한다.

핵심 흐름은 이렇다.

`단축키 누름 → 마이크 녹음 → 로컬 모델 추론 → 텍스트가 커서 위치에 자동 입력`

## 외워야 할 핵심 용어 5개

| 용어 | 초보자식 설명 |
|---|---|
| STT | Speech-to-Text, 음성을 텍스트로 변환하는 기술 |
| Whisper | OpenAI가 오픈소스로 공개한 다국어 음성 인식 모델, 68만 시간 데이터로 학습 |
| Parakeet V3 | NVIDIA가 공개한 STT 모델, CPU만으로도 실시간의 5배 속도로 변환 |
| Push-to-Talk | 버튼을 누르는 동안만 녹음하고, 손을 떼면 자동 변환이 시작되는 인터페이스 방식 |
| VAD | Voice Activity Detection, 음성이 있는 구간만 골라내 묵음을 자동으로 제거하는 기능 |

## 예를 들어 설명하면

STT 도구 선택 기준은 용도에 따라 달라진다.

| 도구 | 처리 방식 | 프라이버시 | 한국어 지원 | 비용 |
|---|---|---|---|---|
| Handy | 로컬(오프라인) | 완전 보장 | Whisper 모델 지원 | 무료 |
| OpenAI Whisper API | 클라우드 | 서버 전송 | 우수 | 분당 $0.006 |
| 네이버 클로바노트 | 클라우드 | 서버 전송 | 한국어 최적화 | 월 300분 무료 |
| Google Docs 음성입력 | 클라우드 | 서버 전송 | 지원 | 무료 |

GPU가 있는 환경이라면 Whisper Medium 또는 Turbo가 속도와 정확도의 균형이 좋다. GPU 없는 노트북이라면 Parakeet V3가 현실적인 선택이다. Whisper Large V3의 평균 단어 오류율(WER)은 7.4%로 상용 클라우드 서비스와 동등한 수준이다.

## 이 단계에서 중요한 판단 기준

기업 기밀이나 민감 정보를 다루거나 인터넷이 없는 환경이라면 Handy, 한국어 정확도가 최우선이거나 화자 분리가 필요하다면 클로바노트가 더 적합하다.

## 한 줄 요약 — 이것만 기억하면 된다

**음성 데이터를 외부로 보내지 않고 내 PC에서 끝내야 할 때, Handy는 설치부터 사용까지 가장 현실적인 로컬 STT 선택지다.**

## 나중에 더 깊게 들어가면

- Whisper 모델 크기(Small/Medium/Large)에 따른 정확도와 속도 트레이드오프
- llama.cpp나 faster-whisper로 CLI에서 직접 배치 변환하는 방법
- 화자 분리(Speaker Diarization)를 결합해 회의록 자동 분류하는 파이프라인
