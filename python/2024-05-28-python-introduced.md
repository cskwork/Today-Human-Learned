# Python 입문 — 왜 Python인가

> **TL;DR**
> Python은 사람이 읽기 쉽게 설계된 고수준 인터프리터 언어로, 웹·데이터·AI 등 거의 모든 분야에서 쓰인다.

---

## Python를 왜 쓰는지 감 잡기

프로그래밍 언어는 사람이 컴퓨터에 명령을 전달하는 수단이다. 기계어(0과 1)에 가까울수록 컴퓨터가 이해하기 쉽지만, 사람이 쓰기 어렵다. Python은 반대 방향을 택했다. 영어 문장처럼 읽히는 문법으로 사람의 생산성을 높이고, 내부 번역은 인터프리터가 담당한다.

웹 서버(Django, FastAPI), 데이터 분석(Pandas), 머신러닝(TensorFlow, PyTorch) 모두 Python 생태계 위에 있다. 하나의 언어로 이 넓은 영역을 커버할 수 있어 입문 언어로 선호도가 높다.

초보자는 처음에 이렇게 이해하면 된다.

`핵심 흐름: 소스 코드(.py) → 인터프리터 실행 → 결과 즉시 출력`

## 외워야 할 핵심 용어 5개

| 용어 | 초보자식 설명 |
|---|---|
| 고수준 언어 | 기계보다 사람에게 가까운 언어. 하드웨어 세부사항을 숨겨 준다. |
| 인터프리터 | 코드를 줄 단위로 읽고 바로 실행하는 프로그램. 컴파일 단계가 없어 빠르게 테스트할 수 있다. |
| 표준 라이브러리 | Python 설치 시 함께 제공되는 기본 도구 모음. 파일 처리, 날짜 계산 등 자주 쓰는 기능이 들어 있다. |
| 서드파티 모듈 | 외부 개발자가 만들어 배포한 추가 라이브러리. pip로 설치한다. |
| 들여쓰기 | Python에서 코드 블록을 구분하는 방법. 중괄호 대신 일정한 공백으로 구조를 표현한다. |

## 예를 들어 설명하면

두 수를 더해 결과를 출력하는 가장 간단한 Python 프로그램이다.

```python
def add_numbers(a, b):
    return a + b

result = add_numbers(5, 3)
print("합계:", result)  # 출력: 합계: 8
```

이 세 줄이 Python의 핵심 구조를 담고 있다. 함수를 정의하고(`def`), 호출하고, 결과를 출력한다. 컴파일 없이 파일을 저장하고 `python 파일명.py`를 실행하면 즉시 결과가 나온다.

## 이 단계에서 중요한 판단 기준

Python을 배울 때는 문법 암기보다 "이 문장이 무엇을 하는가"를 읽는 훈련이 먼저다. 문법이 영어에 가깝기 때문에 코드를 소리 내어 읽으면 의미가 드러나는 경우가 많다.

## 한 줄 요약 — 이것만 기억하면 된다
