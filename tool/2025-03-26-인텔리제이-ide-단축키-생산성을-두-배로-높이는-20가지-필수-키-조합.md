# 인텔리제이 핵심 단축키 — 손이 키보드를 떠나지 않아야 하는 이유

> **TL;DR**
> 인텔리제이 단축키는 카테고리별로 체계가 잡혀 있다. 20개를 한꺼번에 외우려 하지 말고, 탐색 5개부터 시작해 매주 카테고리 하나씩 추가하면 2주면 충분하다.

---

## 단축키를 왜 써야 하는지 감 잡기

마우스로 메뉴를 클릭하는 동작은 생각보다 비싸다. 눈이 화면 상단으로 이동하고, 손이 마우스로 옮겨가고, 메뉴 계층을 탐색하는 동안 코딩 흐름이 끊긴다. 단축키는 이 흐름 단절을 없앤다. 특히 리팩토링처럼 같은 작업을 수십 번 반복할 때 차이가 크다.

인텔리제이 단축키는 다섯 카테고리로 나뉜다.

`핵심 흐름: 탐색 → 편집 → 리팩토링 → 검색 → 실행/디버그`

## 외워야 할 핵심 용어 5개

| 용어 | 초보자식 설명 |
|---|---|
| Search Everywhere | 더블 Shift. 클래스, 파일, 액션 무엇이든 한 곳에서 검색 |
| Go to Declaration | Ctrl+B / Cmd+B. 메서드·변수가 정의된 곳으로 바로 이동 |
| Show Intention Actions | Alt+Enter / Option+Enter. 오류·경고 위에서 누르면 자동 수정 제안 목록 출력 |
| Reformat Code | Ctrl+Alt+L / Cmd+Option+L. 코드 스타일 설정에 맞춰 들여쓰기·공백 자동 정렬 |
| Refactor This | Ctrl+Alt+Shift+T / Ctrl+T. 현재 위치에서 가능한 모든 리팩토링 옵션 목록 출력 |

## 예를 들어 설명하면

카테고리별 핵심 단축키를 표로 정리했다. Windows/Linux와 macOS 기준을 함께 표기한다.

| 카테고리 | 기능 | Windows/Linux | macOS |
|---|---|---|---|
| 탐색 | Search Everywhere | Double Shift | Double Shift |
| 탐색 | Go to Class | Ctrl+N | Cmd+O |
| 탐색 | Go to File | Ctrl+Shift+N | Cmd+Shift+O |
| 탐색 | Recent Files | Ctrl+E | Cmd+E |
| 탐색 | Go to Declaration | Ctrl+B | Cmd+B |
| 편집 | Smart Code Completion | Ctrl+Shift+Space | Ctrl+Shift+Space |
| 편집 | Complete Statement | Ctrl+Shift+Enter | Cmd+Shift+Enter |
| 편집 | Duplicate Line | Ctrl+D | Cmd+D |
| 편집 | Comment Line | Ctrl+/ | Cmd+/ |
| 편집 | Reformat Code | Ctrl+Alt+L | Cmd+Option+L |
| 리팩토링 | Rename | Shift+F6 | Shift+F6 |
| 리팩토링 | Extract Variable | Ctrl+Alt+V | Cmd+Option+V |
| 리팩토링 | Extract Method | Ctrl+Alt+M | Cmd+Option+M |
| 리팩토링 | Show Intention Actions | Alt+Enter | Option+Enter |
| 리팩토링 | Refactor This | Ctrl+Alt+Shift+T | Ctrl+T |
| 검색 | Find | Ctrl+F | Cmd+F |
| 검색 | Find in Path | Ctrl+Shift+F | Cmd+Shift+F |
| 검색 | Replace | Ctrl+R | Cmd+R |
| 검색 | Find Action | Ctrl+Shift+A | Cmd+Shift+A |
| 실행/디버그 | Run | Shift+F10 | Ctrl+R |
| 실행/디버그 | Debug | Shift+F9 | Ctrl+D |

## 이 단계에서 중요한 판단 기준

단축키가 OS 단축키와 충돌하면 Settings > Keymap에서 재지정하면 된다. 충돌 여부는 Find Action(Ctrl+Shift+A)에서 단축키 이름으로 검색하면 즉시 확인할 수 있다.

## 한 줄 요약 — 이것만 기억하면 된다

**탐색 5개(Search Everywhere, Go to Class, Go to File, Recent Files, Go to Declaration)만 먼저 체화하면 나머지는 자연스럽게 따라온다.**

## 나중에 더 깊게 들어가면

- Key Promoter X 플러그인: 마우스 클릭 시 해당 단축키를 팝업으로 알려줌
- 커스텀 키맵 내보내기/공유 방법
- Live Template으로 자주 쓰는 코드 패턴 단축키 등록
