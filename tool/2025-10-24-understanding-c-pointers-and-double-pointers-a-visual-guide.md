# C 포인터와 이중 포인터: 메모리 주소를 다루는 법

> **TL;DR**
> 포인터는 값이 아니라 메모리 주소를 저장하는 변수이고, 이중 포인터는 그 포인터의 주소를 저장한다. 간접 참조의 층수가 하나씩 늘어나는 구조다.

---

## 포인터를 왜 쓰는지 감 잡기

C에서 변수를 만들면 메모리 어딘가에 공간이 잡히고 값이 들어간다. `int age = 25;`라고 쓰면 4바이트 공간에 25가 저장된다. 이 공간에는 집 주소처럼 고유한 메모리 주소가 붙어 있다.

포인터는 이 주소를 값으로 저장하는 변수다. 책 내용을 통째로 전달하는 대신 책이 꽂힌 서가 위치만 알려주는 것과 같다. 큰 데이터를 함수에 넘길 때 복사 비용 없이 위치만 전달하거나, 함수 밖에서 같은 데이터를 여러 곳이 공유해야 할 때 포인터를 쓴다.

초보자는 이렇게 이해하면 된다.

`핵심 흐름: 변수(값 저장) → 포인터(주소 저장) → 이중 포인터(포인터의 주소 저장)`

## 외워야 할 핵심 용어 5개

| 용어 | 초보자식 설명 |
|---|---|
| 메모리 주소 | RAM 안에서 각 바이트에 붙은 고유 번호. `0x1000` 같은 16진수로 표현한다. |
| 포인터 | 메모리 주소를 담는 변수. `int *ptr`처럼 타입 뒤에 `*`를 붙여 선언한다. |
| `&` (주소 연산자) | 변수의 주소를 가져온다. `&age`는 "age가 저장된 메모리 주소"를 반환한다. |
| `*` (역참조 연산자) | 포인터가 가리키는 주소의 값을 읽거나 쓴다. `*ptr = 30`처럼 사용한다. |
| 이중 포인터 | 포인터를 가리키는 포인터. `int **ptr2`처럼 `*`를 두 개 붙인다. |

## 예를 들어 설명하면

```c
int age = 25;
int *ptr = &age;      // ptr은 age의 주소를 저장
int **ptr2 = &ptr;    // ptr2는 ptr의 주소를 저장

// 세 가지 방법이 모두 같은 값을 읽는다
printf("%d\n", age);    // 25
printf("%d\n", *ptr);   // 25
printf("%d\n", **ptr2); // 25

// 이중 포인터의 실용 예: 문자열 배열 순회
char *names[] = {"Alice", "Bob", "Charlie"};
char **p = names;
printf("%s\n", *(p + 1)); // "Bob"
```

`*(p + 1)`은 "p를 한 칸 앞으로 이동한 뒤, 그 포인터가 가리키는 값을 읽어라"는 뜻이다. 배열의 두 번째 원소("Bob")를 가리키는 포인터를 역참조한 결과다.

## 이 단계에서 중요한 판단 기준

함수 안에서 포인터 자체가 가리키는 대상을 바꿔야 할 때(즉, 포인터를 함수에서 수정해야 할 때) 이중 포인터가 필요하다. 단순히 포인터가 가리키는 값만 바꾸는 것이라면 단일 포인터로 충분하다.

## 한 줄 요약 — 이것만 기억하면 된다

**포인터는 메모리 주소를 담는 변수이고, 이중 포인터는 그 포인터의 주소를 한 겹 더 감싼 것이다.**
